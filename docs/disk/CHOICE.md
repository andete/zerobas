# `CHOICE` ($4019) and `MTOFF` ($401F), disk ROM

> **Spec:** DRAFT 1 (2026-11-22), one measured round on two references, no review yet.
> Two small driver entries on one page, sharing one probe.

## Summary

Called with CALSLT into the disk interface's slot:

- **CHOICE** answers HL = a pointer into the disk ROM (page 1) -- the text a FORMAT shows to choose the
  disk type; its bytes are the ROM's own and are not read here -- the same whatever B and C are, with A 0,
  F 0 and BC and DE as entered. It writes nothing.
- **MTOFF** writes nothing and keeps DE; its A, F, BC and HL are the interface's own (the NMS 1200 and the
  CF-3300 answer differently).

zerobas's CHOICE answers a page-1 pointer and the same registers; its MTOFF answers as the CF-3300's. No
difference from the references on what this page pins.

## The specification

References: the Philips VG-8020 with an NMS 1200 disk interface (row `D`) AND the National CF-3300
(row `C`). Ours: zerobas's disk build.

**Evidence.** **[XH rNN]**: case `NN` on row `r` of the XCHOICE1 probe -- run 1
([`scratchpad/XCHOICE1_run1.out`](../../scratchpad/XCHOICE1_run1.out), `--row both`: the disk section),
run 2 ([`scratchpad/XCHOICE1_run2.out`](../../scratchpad/XCHOICE1_run2.out), `--row cf3300`).
`probes/bios/spec/xchoice1.asm` documents the 6 cases (CHOICE with B / C $00, $F9, $FF; MTOFF with
$00, $FF, $12 / $34) and the 30-byte record: A, F, B, C, D, E, H, L, the interrupt state after, and the
first 21 bytes of a 32-byte buffer of $E5 at HL's entry value ($A400). XDENT1's frame (CALSLT, A 0, F 0, DE
0). On a first run's NODISK row zerobas never finished: its diskless DRVTBL names a disk interface in slot 1
(D-DRVTBLNODISK, measured by `probes/bios/spec/xdrvtbl.asm`,
[`scratchpad/XDRVTBL_run1.out`](../../scratchpad/XDRVTBL_run1.out)), so the probe called "CHOICE" in its
own cartridge. The probe now checks H.PHYD (a bare RET: no interface) before DRVTBL, as a ROM does; no
rule reads the NODISK row.
