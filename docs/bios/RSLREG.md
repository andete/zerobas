# `RSLREG` ($0138) — read the primary slot register

> **Spec:** FINAL (2026-11-18), the core rule: the review's one unpinned rule (RSLREG after WSLREG's own
> value) measured in round 2; its other items are open (§7's small-call stop). Measured on the VG-8020, alone and with a disk interface, and on
> the CF-3300: 16 slot-register values in two passes (entry F, interrupts and register markers
> differ).

## Summary

`RSLREG` returns the primary slot register ($A8) in A, as the port holds it (measured with pages 1
and 2 set to every slot, page 0 at slot 0 and page 3 at slot 3). It keeps F, BC,
DE, HL, IX, IY and the interrupt state as on entry.

zerobas does all of it the same.

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`), and the National CF-3300's (row `C`). Ours: the C-BIOS repack, diskless on row `N`, the
disk build on `D` and `C`.

**Evidence.** **[XS rNN]**: case `NN` of the XRSLREG probe, run 2, on row `r`:
[`scratchpad/XRSLREG_run2.out`](../../scratchpad/XRSLREG_run2.out) (`N`),
[`scratchpad/XRSLREG_run2d.out`](../../scratchpad/XRSLREG_run2d.out) (`D`),
[`scratchpad/XRSLREG_run2c.out`](../../scratchpad/XRSLREG_run2c.out) (`C`).
`probes/bios/spec/xrslreg.asm` documents the passes and the 10-byte record:
- The probe runs from RAM in page 3. Each case calls WSLREG with a value that keeps page 0 at slot 0
  (the BIOS) and page 3 at its boot slot, and sets pages 1 and 2 to one of the 16 slot pairs. It
  then reads the register by hand, writes it by hand with pages 1 and 2 flipped (so RSLREG cannot
  return a remembered value), calls RSLREG, and puts the boot value back by hand.
- Pass 0 (cases 00-15): entry F $00, interrupts off, register markers as listed. Pass 1 (cases
  16-31): entry F $FF, interrupts on, every marker complemented. RSLREG's entry A is $A5, then $5A.
- BC, DE, HL, IX and IY carry markers. The interrupt state is read twice after each call.
- The register's boot value is $F4 on rows `N` and `C`, $F8 on row `D`'s reference (its cartridge
  is in slot 2): the harness reports that header byte as a difference on row `D`. It is set-up, not
  an output of either call, and only its page-3 field (slot 3 everywhere) enters the cases.

## Differences from the reference

None measured: every rule holds on zerobas.

## Open (not measured)

- **[A]** Bits 0-1 and 6-7 with other values, so "the whole byte" against "bits 2-5": page 0 holds
  the BIOS entry itself, so it cannot be switched through it; page 3 could, with the stack and the
  probe's code in page-2 RAM.
- **[A]** Entry F crossed with the interrupt state (each pass has one pair).
- **[A]** The alternate registers and SP; RAM; the time it takes.
- **[A]** Entry F other than $00 and $FF.
