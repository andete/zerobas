# `CHRGTR` ($0010) — the next character of a BASIC text

> **Spec:** FINAL (2026-11-18), the core rule: the second test-writer review found no unpinned rule and
> no new behaviour; its other items are open (§7's small-call stop). Measured on the Philips VG-8020:
> every byte value 0-255 after the text pointer in two passes (entry A / F, register markers and the
> constant-token cells' seeds all differ); then three calls in a row from each numeric token.

## Summary

`CHRGTR` (also `RST 10h`) steps HL to the next character of a BASIC text and returns it in A. Z is
set at the end of a statement (00 or `:`) and the carry on a digit `0`-`9`.

It skips a space, a TAB and an LF. A numeric-constant token ($0B-$1F) is decoded into the
work area: the text address after the constant, the token, the type and the value. HL then holds
$46E6, not a text pointer; the next call from there returns the text after the constant, so a caller
stepping through the text goes on as if the constant were one character. Token $10 resumes at the
saved text address, and $1E returns the saved token.

zerobas's diskless build does the plain characters the same. It skips only the space, returns other
flags at the end of the line, and treats the tokens as plain characters.

## The specification

Reference: the Philips VG-8020's main BIOS. Ours: the C-BIOS repack.

**Evidence.** **[XC p.n]**: pass `p`, byte value `n` (in hex), of the XCHRGTR probe, run 4,
[`scratchpad/XCHRGTR_run4.out`](../../scratchpad/XCHRGTR_run4.out).
`probes/bios/spec/xchrgtr.asm` documents the set-up and the 20-byte record:
- The text at $E900 is `X`, the byte `n`, `1`-`9`, then 00. HL points at the `X` on entry.
- Pass 0: entry A $A7, F $00; CONTXT ($F666) holds $E920, where the text is a space, `A`, 00; CONSAV
  and the cells after it ($F668-$F671) hold $61-$6A, one value per cell.
- Pass 1: entry A $00, F $FF, every register marker complemented; CONTXT $E930 → `B`, `A`, 00; the
  cells $71-$7A.
- BC, DE, IX and IY carry markers and are compared after the call.
- The probe runs from RAM with the main ROM in page 1: on the VG-8020 the interpreter entries
  continue into the BASIC ROM there.

**[XC2 p.t]**: token `t` of the XCHRGTR2 probe, run 1,
[`scratchpad/XCHRGTR2_run1.out`](../../scratchpad/XCHRGTR2_run1.out)
(`probes/bios/spec/xchrgtr2.asm`): the text `X`, `t`, `1`-`9`, `:`, 00, the cells as pass 0, then
CHRGTR three times, each from the HL the one before returned; pass 1 with entry F $FF on every call.

Run 1 is discarded: it left CONTXT at $5A5A, inside the ROM, so token $10 read from there.

## Open (not measured)

- **[A]** More than one byte to skip in a row, and a skip in front of a token or 00.
- **[A]** A token $10 whose CONTXT text is itself a token; $1E with CONSAV a token.
- **[A]** A CONTXT text that starts with a TAB or an LF, 00, ':' or a digit (only 'A' and 'B' were measured).
- **[A]** A space or 00 right after a numeric constant (the chain's second call meeting a skip or the end).
- **[A]** Which saved pointer the call after a numeric token reads: CONTXT, or another copy (every case leaves both
  the same; overwriting CONTXT between the calls would tell).
- **[A]** Other bytes after a constant than `1`-`9` (one value pattern), and an entry HL other than $E900.
- **[A]** The registers across the chain's calls (XCHRGTR2 neither seeds nor compares them).
- **[A]** The hook H.CHRG ($FF48): the probe leaves it as the boot left it.
- **[A]** The alternate registers and SP: not seeded with markers nor compared.
- **[A]** RAM outside $F666-$F671 and the stack; the time it takes; interrupts on.
- **[A]** zerobas's disk build (only the diskless row was run); the CF-3300 (the second reference).
