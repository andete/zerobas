# `SETGRP` ($007E) — set the VDP up for high-resolution graphics

> **Spec:** DRAFT 2 (2026-11-18), after one test-writer review, measured again (run 2). Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`SETGRP` programs the VDP for high-resolution graphics (graphic 2) from the work area, without
touching VRAM:
- RG0SAV gets bit 1 set (M3), its other bits kept; RG1SAV keeps bits 7-5 and 2-0, with bits 4 and
  3 clear;
- RG2SAV-RG6SAV := GRPNAM / $400, GRPCOL / $40 OR $7F, GRPCGP / $800 OR $03, GRPATR / $80, GRPPAT /
  $800, each cell shifted right; RG7SAV is not touched;
- the VDP registers R#0-R#6 get those values.

It leaves SCRMOD and the cells alone, returns A = the new RG6SAV, F = $00, BC = $0007, DE = $7F03, HL = $F3D1, and
interrupts **on**.

zerobas programs the VDP the same and leaves VRAM, SCRMOD and the interrupts as the VG-8020 does.
It differs in the shadow bytes it stores and in RG0SAV, and in the registers it returns (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` of the XSET probe, run 2, on row `r`, both rows in
[`scratchpad/XSET_run2.out`](../../scratchpad/XSET_run2.out) (the two rows recorded the same bytes).
`probes/bios/spec/xset.asm` documents the presets, the table sets, the case table and the 112-byte
record:
- Before each case the probe sets, by hand: the 20 screen-table cells TXTNAM ($F3B3) .. MLTPAT
  ($F3D9) to one of four sets (0 the published defaults; 1 other aligned values; 2 other values,
  most with low bits set -- SETGRP's are all $3FFF; 3 every cell $FFFF); RG0SAV / RG1SAV to $00 /
  $00, $FF / $FF, $5A / $A5, or (cases 48-63) apart: $01 / $00, $FE / $FF; RG2SAV-RG6SAV to $A5;
  RG7SAV and SCRMOD to the case's ($A5 and $77 in cases 00-47; $00, $FF, $5A and 0-3 in 48-63);
  the VDP registers to $00 $80 $06 $80 $00 $36 $07 $F4; every VRAM byte to (address low) XOR
  (address high) XOR $5A.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (complemented in odd cases), A $A7, entry F and
  interrupts as the case lists them.
- After the call it records every register, the interrupt state, RG0SAV-RG7SAV, SCRMOD, the VDP
  registers R#0-R#7 as the VDP holds them (written into the record by the emulator's debugger,
  `@vdpsnap` in [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)), the 16-bit sums of
  VRAM's sixteen 1 KB blocks (read with R#1 := $80 first, so all 16 KB are addressed), and the 20
  screen-table cells.
- SETTXT: cases 00-11 and 48-51; SETT32: 12-23 and 52-55; SETGRP: 24-35 and 56-59; SETMLT: 36-47 and
  60-63.

## Differences from the reference

| TODO item | rules zerobas fails |
|---|---|
| **D-SETSHADOW** (zerobas stores the cells' shifted values with junk in RG2SAV-RG6SAV's top bits -- $CF for $3D23, $FF for $FFFF -- where the VG-8020 stores a plain shift; the VDP drops those bits, so the registers agree, and its RG0SAV clears bits 3-2 (SETGRP) or keeps bits 7-4 (SETMLT) where the VG-8020 keeps them / clears them) | R-GR-SHADOW, R-GR-R01 |
| **D-SETREGS** (zerobas returns other DE and HL -- DE the address past the mode's cells, HL $0000 or $FFE0; its F is $00 as there, and its A differs only where its RG6SAV does, D-SETSHADOW) | R-GR-REGS |
