# `WRTVDP` ($0047) — write a VDP register

> **Spec:** FINAL (2026-11-18), the core rules: the second test-writer review found no unpinned rule and no new
> behaviour; its other items are open (§7's small-call stop). Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`WRTVDP` writes B to VDP register C AND 7, and to the work area at RG0SAV + C ($F3DF + C): the
register's shadow for C 0-7, and further bytes of the work area for any higher C. The VDP keeps only
the bits each register has (R#2's low four, for example).

It returns with A = B, B = 0, C kept and F $A0 or $A4 (P/V set when C OR $80 has an even number of 1
bits), and with interrupts **on**, whatever they were before. DE, HL, IX and IY are kept.

zerobas does all of it the same, C $80 and $FF included (D-WRTVDPC, 2026-11-20, cbios-repack/vdp-calls.patch: C kept, B stored at
RG0SAV + C).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XV rNN]**: case `NN` of the XVDPREG probe, run 4, on row `r`, both rows in
[`scratchpad/XVDPREG_run4.out`](../../scratchpad/XVDPREG_run4.out); a second run,
[`scratchpad/XVDPREG_run4_repeat.out`](../../scratchpad/XVDPREG_run4_repeat.out), recorded the same bytes.
`probes/bios/spec/xvdpreg.asm` documents the case table and the 32-byte record:
- Before each case the probe sets, by hand: the VDP registers R#0-R#7 to $00 $C0 $06 $80 $00 $36 $07
  $F4 (R#1's interrupt bit clear); RG0SAV-RG7SAV ($F3DF-$F3E6) to $30-$37, then RG1SAV to the case's
  value; $F3E7-$F3EE to the bytes they held at boot (recorded once, at the start of the capture);
  sprite 0's Y to $D0 (no sprite shown). It saves the byte at RG0SAV + C and puts it back after the
  record. It reads the VDP status once, to clear it.
- A is $A7, DE $9BDF, HL $2468, IX $4321, IY $8765, every one complemented in odd cases; B and C as
  the case lists them; entry F $00 or $FF; interrupts on or off.
- After the call it records A, F, B, C, whether DE / HL / IX / IY moved, the interrupt state,
  RG0SAV-RG7SAV, $F3E7-$F3EE and the byte at RG0SAV + C. Then the CPU reaches a probe address where
  the emulator's debugger writes the VDP registers R#0-R#7 into the record (`@vdpsnap` in
  [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)): the registers as the VDP holds them,
  read from the hardware, not from any ROM.
- WRTVDP: cases 00-31 (C 0-7, B $00, $FF, $5A, $A5, each B with its own entry F and interrupt
  state), 32-39 and 64-71 (C 8-15, B $5A and $A5), 72-75 (C $10, $28, $80, $FF). DISSCR: 40-47,
  ENASCR: 48-55, RG1SAV $00, $FF, $A0, $E2, $5A, $A5, $40, $BF. RDVDP: 56-63 and 76-79 -- after a
  wait of more than a frame (B = 1); with none (B = 0); with five sprites set up on one line and the
  status polled until its frame flag, then the wait (B = 2); or the wait and an RDVDP of the probe's
  own first (B = 3). B = 0 and B = 1 meet all four pairs of entry F ($00, $FF) and interrupt state; B = 2
  and B = 3 meet F $00 with interrupts off and F $FF with them on.
- $F3E7-$F3EE differ between the machines at boot (two bytes): set-up, which every case starts from
  and the rules compare with each machine's own boot copy. The harness reports them as differences.

## On later generations (MSX2, MSX2+)

Measured 2026-11-23 on the HB-F900 and NMS 8250 (MSX2) and the FS-A1WSX (MSX2+): this page's probes through `probes/bios/biosl_run.py --row msx2all` -- [scratchpad/AE_m1on2/xvdpreg.out](../../scratchpad/AE_m1on2/xvdpreg.out); triage: [scratchpad/m1on2-triage-vdp.md](../../scratchpad/m1on2-triage-vdp.md) (xvdpreg was read after it, R#8-R#23 restored after each case on the MSX2s).

| rule | MSX2 (HB-F900, NMS 8250) | MSX2+ (FS-A1WSX) |
|---|---|---|
| **R-WV-REG** | C 0-7 holds, at the V9938's widths (below); C 8-15, $10, $28 and $FF write none of R#0-R#7; C $80 writes R#0 [M] | the same [M] |
| **R-WV-SAV** | C 8 and above do not store B at RG0SAV + C: $F3E7-$F3EE keep their bytes, and $F3EF / $F407 / $F45F / $F4DE do not read B [M] | the same [M] |
| **R-WV-ABC** | C 8 and above, and C 0 with B $FF / $A5: A $00, B kept [M] | the same [M] |
| **R-WV-F** | the same cases return F $44 [M] | F $00, $0C or $44 in every case, never $A0 / $A4 [M] |
| every other rule | holds [M] | holds [M] |

Machine differences, not the call's: the V9938 holds other register bits than the TMS9918 (R#1 has no bit 7, the 4 / 16 KB bit: the preset $C0 reads $40; R#0 keeps $7E, R#2 $7F, R#4 and R#6 $3F, R#5 all 8) and has 128 KB of VRAM, so R#0-R#7 read back masked to those bits; the HB-F900's and FS-A1WSX's BDRCLR ($F3EB) is 7.

**On the turbo R** (FS-A1GT / FS-A1ST, measured 2026-11-23, D-TRSPEC): the call's results are the FS-A1WSX's, on both models; the one field that differs is TRGFLG ($F3E8) as the boot leaves it, $89 (the A1WSX $9F), which the probe restores in every record -- the machine's input state, not the call [M] ([AE_trall/xvdpreg.out](../../scratchpad/AE_trall/xvdpreg.out); overview: [turbor/remeasured.md](../turbor/remeasured.md)).

## Open (not measured)

- **[A]** C above 15 other than $10, $28, $80, $FF, and with more than one B each.
- **[A]** B values other than $00, $FF, $5A and $A5 for C 0-7 (each B meets one entry F and one
  interrupt state), and other than $5A / $A5 for C 8-15.
- **[A]** What WRTVDP sends to port $99 (the TMS9918 decodes three register bits, so "C OR $80"
  and "(C AND 7) OR $80" leave the same registers; a port trace would separate them).
- **[A]** Entry with a VDP interrupt pending and R#1's interrupt bit set: whether the interrupt is
  taken between the two port writes or after the call (the probe clears the status first and keeps
  R#1's bit 5 clear at entry), and what the handler then leaves in STATFL.
- **[A]** The VDP's address latch and VRAM address after the call.
- **[A]** Whether WRTVDP masks B itself or the VDP keeps only the register's bits (the snapshot reads
  the registers back, so both look the same; a port trace would tell). Case 25 (R#6 := $FF) cannot
  show the write: $FF masked to R#6's bits is $07, the preset.
- **[A]** Where zerobas writes for C = $FF (the probe records $F4DE only).
- **[A]** The alternate registers and SP; RAM other than $F3DF-$F3EE and RG0SAV + C; the time it takes.
- **[A]** The CF-3300 (the second reference).
