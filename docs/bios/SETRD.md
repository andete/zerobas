# `SETRD` ($0050) — set the VDP address for reading

> **Spec:** DRAFT 1 (2026-11-18), before review. Measured on the VG-8020, alone and with a disk
> interface, with VRAM read back by hand through the VDP's ports after every call.

## Summary

`SETRD` sets the VDP up to read VRAM from HL AND $3FFF: the next read of port $98 returns that byte,
the one after it the next byte, wrapping from $3FFF to $0000.

It returns A = H AND $3F with an AND's flags (H set), keeps BC, DE, HL, IX and IY, and returns with
interrupts **on**, whatever they were before.

zerobas does all of it the same.

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XM rNN]**: case `NN` of the XVRAM probe, run 1, on row `r`, both rows in
[`scratchpad/XVRAM_run1.out`](../../scratchpad/XVRAM_run1.out).
`probes/bios/spec/xvram.asm` documents the case table and the 32-byte record:
- Before each case the probe writes, by hand and slowly (a VRAM access at least 38 T-states from the
  next), 8 VRAM bytes at each of the case's two windows and at the call's own VRAM address (HL AND
  $3FFF; DE AND $3FFF for LDIRVM): each byte := its address's low byte XOR its high byte XOR $5A, so
  each byte names its address. For LDIRMV the windows are RAM, preset to $E0 + i and $E8 + i;
  LDIRVM's source, RAM at $E9A0, holds $80 + i.
- IX is $4321 and IY $8765; A, F, HL, DE, BC and the interrupt state (on or off) as the case lists
  them.
- After the call it records every register, the interrupt state, and the two windows (8 bytes each),
  read back by hand. After SETRD it first reads port $98 twice; after SETWRT it first writes $C7 and
  $C8 to it.
- The screen is as the cartridge finds it at boot (SCREEN 1, the display on).
- Cases: RDVRM 00-05, WRTVRM 06-11, SETRD 12-15, SETWRT 16-19, FILVRM 20-25, LDIRMV 26-29, LDIRVM
  30-33. No case copies 64 KB (BC = 0) from or to RAM: from RAM it would carry ROM bytes into VRAM.

## Open (not measured)

- **[A]** HL values other than the four measured; more than two reads after it.
- **[A]** Entry with a VDP interrupt pending and R#1's interrupt bit set, where the handler would
  run inside or right after the call (the screen's R#1 has the bit set, but the probe keeps
  interrupts off between cases, so none is pending when it calls).
- **[A]** Other screen modes, and the display off (which changes how fast VRAM may be written).
- **[A]** The alternate registers and SP; the time it takes.
- **[A]** The CF-3300 (the second reference).
