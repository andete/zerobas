# `SNSMAT` ($0141) — read a row of the key matrix

> **Spec:** FINAL (2026-11-19), the core rules: the second test-writer review found no new behaviour; the
> separating cases it asked for (run 3) all confirmed the rules. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`SNSMAT` returns key-matrix row A AND $0F in A, as the PPI reads it (a bit 0 for each key pressed);
rows 11 and 15 measured give $FF. It selects the row by setting port C := (port C AND $F0) + A, an 8-bit add of the
whole A (A $12 gives $x2 + $10, A $FF carries out of the high nibble), leaves C = A, keeps B, DE and HL,
and returns with interrupts **on**.

zerobas does all of it the same (since D-SNSMATC / D-SNSMATPORT, 2026-11-19).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XI rNN]**: case `NN` of the XINP1 probe, run 3, on row `r`, both rows in
[`scratchpad/XINP1_run3.out`](../../scratchpad/XINP1_run3.out) (the two rows recorded the same bytes).
The probe turns the VDP's frame interrupt off first (R#1 := RG1SAV AND $DF), so no timer interrupt
scans the keys behind a call, whatever the call does with the interrupt flag.
`probes/bios/spec/xinp1.asm` documents the presets, the case table and the 48-byte record:
- Before each case the debugger sets the keyboard matrix (`@keyset`, probes/bios/biosl_run.py: the
  emulator's key matrix, as a person pressing keys -- no key, or the case's one or two); the probe
  sets PUTPNT / GETPNT to KEYBUF + 5 / + 2 (three keys queued), INTFLG to the case's, CAPST $00,
  TRGFLG $F1, NEWKEY / OLDKEY $FF x 11, the PPI's port C to the case's ($50 unless named) and PSG R15
  to $CF. Nothing is plugged into the joystick ports.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (IX / IY complemented when bit 2 of the case number
  is set), A, F and the interrupt state as the case lists them. After the call it records every
  register, the interrupt state (read twice), port C, PSG R14 / R15, PUTPNT, GETPNT, INTFLG, CAPST,
  TRGFLG, NEWKEY and OLDKEY.
- SNSMAT 00-12 (rows 0, 1, 2, 5-10 with a key, row 8 with none / four, A 11 / $FF); KILBUF 13, 14;
  CHGCAP 15-19 (A 0, 1, $FF, $80); GTSTCK 20-36 (A 0 with the cursor keys, A 1-3); GTTRIG 37-44 (A 0
  without / with the space bar, A 1-5); BREAKX 45-49 (no key, CTRL+STOP, STOP, CTRL); ISCNTC 50, 51;
  CKCNTC 52, 53; GTPAD 54-59 (A 0-4, 7); GTPDL 60-62 (A 1, 2, 12). Cases 10, 14, 19, 36, 44, 49, 51, 53
  enter with F $FF and interrupts on.
- Round 2 (63-80): GTPDL A 1 and GTPAD A 0 / 1 with interrupts on (63-65); CHGCAP A 1 with F $FF, and A
  0 / 1 with port C $A0 (66-68); BREAKX with interrupts on and no key, and SHIFT+STOP (69, 70); SNSMAT A
  $12, A 8 with port C $5A, rows 3 and 4, row 2 with port C $D0 (71-75); GTTRIG A 0 with a cursor key
  (76); GTSTCK with row-8 nibbles $B0 / $D0 / $E0 and with port C $D0 (77-80).
- Round 3 (81-94): GTSTCK A 1-3 with a cursor key held (81-83); BREAKX with F $FF, no key and STOP alone
  (84, 85); ISCNTC / CKCNTC with CTRL+STOP held (86, 87: the flag, not the keys, decides); GTTRIG A 0
  with HOME and with DEL (88, 89); SNSMAT A $20, and row 2 with a key only in row 10 (90, 91); CHGCAP A
  $02 / $40 (92, 93); GTPAD A 2 with interrupts on (94).
