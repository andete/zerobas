# `RIGHTC` ($00FC) — move the graphics position one pixel right

> **Spec:** DRAFT 2 (2026-11-18), after one test-writer review, measured again (run 3). Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`RIGHTC` moves the current graphics position (CLOC, CMASK) one pixel right. In SCREEN 2 the mask
shifts right a bit, and from the cell's last pixel ($01) it becomes $80 with CLOC + 8; in SCREEN 3
the mask flips between $F0 and $0F, and from $0F CLOC moves on 8. It checks no edge. A is the new
mask, F an AND's flags on it; the other registers, the interrupt state and the other cells are kept.

zerobas does all of it the same for a pixel's mask; it treats a SCREEN 3 mask that is not one
differently (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XM rNNN]**: case `NNN` of the XGFX2 probe, run 3, on row `r`, both rows in
[`scratchpad/XGFX2_run3.out`](../../scratchpad/XGFX2_run3.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx2.asm` documents the presets, the case table and the 28-byte record:
- Before each case the probe sets, by hand: CLOC ($F92A) and CMASK ($F92C) to a pixel's position as
  [MAPXYC](MAPXYC.md) gives it, GRPCGP ($F3CB), MLTCGP ($F3D5) and SCRMOD to the case's, ATRBYT to
  $77, ASPCT1 / ASPCT2 to $1234 / $5678.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (IX / IY complemented when bit 2 of the case
  number is set), A $A7, entry F $00 / $FF and interrupts off / on by case. After the call it records
  every register, the interrupt state (read twice), CLOC, CMASK and the other cells.
- Cases 000-125: each of the six calls from 11 SCREEN 2 positions (corners, the 8-pixel and
  character-row edges, a middle point; GRPCGP $2000) and 10 SCREEN 3 positions (MLTCGP $1000), in
  the order RIGHTC, LEFTC, UPC, TUPC, DOWNC, TDOWNC. Cases 126-251: TUPC, then TDOWNC, at the lines
  around each character row's top and bottom, with GRPCGP $0000 / $2000 / $1800 (SCREEN 2) and
  MLTCGP / GRPCGP $0000 / $2000, $1000 / $2000, $1000 / $0000, $0800 / $1800 (SCREEN 3). Cases
  252-276: TUPC / TDOWNC in SCREEN 2 at character rows 7, 8, 15, 16 (GRPCGP $0000 and $2000) and with
  GRPCGP $2100 and $2004, entry A $00 / $FF and other BC / DE / HL; TDOWNC in SCREEN 3 at high bytes
  6, 7 and $85; RIGHTC / LEFTC in SCREEN 3 with CMASK $F1 / $1F (not a pixel's mask).
- Case 255 enters with ASPCT1 / ASPCT2 $0100 / $00C0 (the probe's marker for that case number).
- The rule tables count each case once per row (N and D).
