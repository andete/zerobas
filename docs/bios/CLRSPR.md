# `CLRSPR` ($0069) — clear all sprites

> **Spec:** DRAFT 1 (2026-11-18), before review. Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`CLRSPR` clears every sprite:
- the sprite pattern table, 2048 bytes from PATBAS ($F926), := 0;
- in the attribute table from ATRBAS ($F928), each of the 32 entries gets Y := 209 ($D1, off the
  screen), its pattern number := its plane number (times 4 for 16 x 16 sprites, RG1SAV's bit 1),
  and its colour := FORCLR; X is not written;
- the VDP register R#1 := RG1SAV.

It does this whatever SCRMOD holds, takes the places from ATRBAS / PATBAS rather than the
screen-table cells, and returns with interrupts **on**.

zerobas writes the same VRAM in SCREEN 1-3. It does not write R#1, does nothing at all in SCREEN 0,
writes Y $D9 for SCRMOD $77, and returns other registers (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XC rNN]**: case `NN` of the XCLR probe, run 2, on row `r`, both rows in
[`scratchpad/XCLR_run2.out`](../../scratchpad/XCLR_run2.out) (the two rows recorded the same bytes).
`probes/bios/spec/xclr.asm` documents the presets, the case table and the 128-byte record:
- Before each case the probe sets, by hand: the 20 screen-table cells to the published defaults
  (set 0) or moved ones (set 1: T32COL $0FC0, T32ATR $3F80, T32PAT $1000 among them); SCRMOD,
  RG1SAV, FORCLR / BAKCLR / BDRCLR, ATRBAS and PATBAS to the case's; RG0SAV and RG2SAV-RG7SAV to
  $A5; the VDP registers to $00 $80 $06 $80 $00 $36 $07 $F4 (R#1's interrupt bit clear, display
  off); every VRAM byte to ((address low) XOR (address high) XOR $5A) OR the block number (address /
  $400), so the sixteen 1 KB blocks sum to sixteen different values.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (complemented in odd cases), A $A7, entry F $00
  in even cases and $FF in odd ones, interrupts off or on.
- After the call it records every register, the interrupt state, RG0SAV-RG7SAV, SCRMOD, FORCLR /
  BAKCLR / BDRCLR, the VDP registers as the VDP holds them (written into the record by the
  emulator's debugger, `@vdpsnap` in [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)),
  the 16-bit sums of VRAM's sixteen 1 KB blocks (read with R#1 := $80 first) and three 16-byte VRAM
  windows.
- CLRSPR: cases 00-11 -- SCRMOD 0, 1, 2, 3, $77; RG1SAV $E0, $E2, $E3, $F0; FORCLR 15, $0A, $FF;
  ATRBAS / PATBAS $1B00 / $3800 or $1F80 / $2000; cell sets 0 and 1. CHGCLR: cases 12-23 -- SCRMOD 0,
  1, 2, 3, $77; colours 15 / 4 / 7, $1A / $25 / $3C, 0 / 0 / 0, 15 / 15 / 15; cell sets 0 and 1.
