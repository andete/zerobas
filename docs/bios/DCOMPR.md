# `DCOMPR` ($0020) — compare HL with DE

> **Spec:** FINAL (2026-11-18), the core rule: one test-writer review found no unpinned rule and no new
> behaviour; its other items are open (§7's small-call stop). Measured on the Philips VG-8020: every
> combination of H, D, L and E over seven values (2401 cases), so that "A = H − D or L − E" separates
> from other forms and unsigned from signed comparison; then four cases with every entry flag set.

## Summary

`DCOMPR` (also `RST 20h`) compares HL with DE as unsigned 16-bit numbers. Z is set when they are equal
and the carry when HL is below DE.

It does this by subtracting high bytes, then, only if they are equal, low bytes. A and the rest of F
are what that subtraction leaves: A = H − D when the high bytes differ, L − E when they are equal. BC,
DE, HL, IX and IY are kept.

zerobas's diskless build does all of it the same.

## The specification

Reference: the Philips VG-8020's main BIOS. Ours: the C-BIOS repack.

**Evidence.** **[XD n]**: case `n` of the XDCOMPR probe, run 1,
[`scratchpad/XDCOMPR_run1.out`](../../scratchpad/XDCOMPR_run1.out).
`probes/bios/spec/xdcompr.asm` documents the order and the 3-byte record:
- H, D, L and E each take one of {00, 01, 5A, 7F, 80, FE, FF}: every combination, h outermost.
- Entry A is $A7 and entry F $00. BC, IX and IY carry markers; BC, DE, HL, IX and IY are compared after
  the call.
- Four more cases have entry F $FF (HL / DE = 1234 / 1234, 1234 / 1235, 1235 / 1234, 0000 / FFFF).
- The block ends in a sentinel byte that the decoder requires.

## Open (not measured)

- **[A]** SP, and what DCOMPR writes below it beyond its return address (the run finishing shows SP
  comes back; the stack's bytes are not compared).
- **[A]** Entry F $FF on the path "high bytes differ, HL > DE" (Z and C clear): entry F $FF meets only
  the other paths.
- **[A]** BC / IX / IY with a second set of values, and one result per register (the probe folds them
  into one byte).
- **[A]** RAM outside the stack; the time DCOMPR takes; other calling contexts (the probe calls it as
  `RST 20h` from a page-1 cartridge with interrupts off).
- **[A]** The alternate registers and I; the interrupt state (the probe runs with interrupts off).
- **[A]** zerobas's disk build (only the diskless row was run).
- **[A]** Entry A other than $A7 (A is overwritten on every measured path).
