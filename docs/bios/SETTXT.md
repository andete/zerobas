# `SETTXT` ($0078) — set the VDP up for 40-column text

> **Spec:** DRAFT 1 (2026-11-18), before review. Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`SETTXT` programs the VDP for 40-column text from the work area, without touching VRAM:
- RG0SAV keeps only its bit 0; RG1SAV keeps bits 7-5 and 2-0, with bit 4 set and bit 3 clear (the
  text mode);
- RG2SAV-RG6SAV := TXTNAM / $400, TXTCOL / $40, TXTCGP / $800, TXTATR / $80, TXTPAT / $800, each
  cell shifted right (its low bits dropped); RG7SAV is not touched;
- the VDP registers R#0-R#6 get those values.

It leaves SCRMOD alone, returns A = the new RG6SAV, F = $00, BC = $0007, DE = 0, HL = $F3BD, and
interrupts **on**.

zerobas programs the VDP the same and leaves VRAM, SCRMOD and the interrupts as the VG-8020 does.
It differs in the shadow bytes it stores, and in the registers it returns (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` of the XSET probe, run 1, on row `r`, both rows in
[`scratchpad/XSET_run1.out`](../../scratchpad/XSET_run1.out) (the two rows recorded the same bytes).
`probes/bios/spec/xset.asm` documents the presets, the table sets, the case table and the 64-byte
record:
- Before each case the probe sets, by hand: the 20 screen-table cells TXTNAM ($F3B3) .. MLTPAT
  ($F3D9) to one of four sets (the published defaults; moved; moved with junk in the low bits;
  every cell $FFFF); RG0SAV / RG1SAV to $00 / $00, $FF / $FF or $5A / $A5, and RG2SAV-RG7SAV to
  $A5; SCRMOD to $77; the VDP registers to $00 $80 $06 $80 $00 $36 $07 $F4; every VRAM byte to $5A.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (complemented in odd cases), A $A7, entry F $00
  in even cases and $FF in odd ones, interrupts off or on.
- After the call it records every register, the interrupt state, RG0SAV-RG7SAV, SCRMOD, the VDP
  registers R#0-R#7 as the VDP holds them (written into the record by the emulator's debugger,
  `@vdpsnap` in [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)), and the 16-bit sums of
  VRAM's sixteen 1 KB blocks, read back through the VDP's ports.
- SETTXT: cases 00-11; SETT32: 12-23; SETGRP: 24-35; SETMLT: 36-47 -- each set of cells with each
  RG0SAV / RG1SAV pair.

## Differences from the reference

| TODO item | rules zerobas fails |
