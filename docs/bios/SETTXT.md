# `SETTXT` ($0078) — set the VDP up for 40-column text

> **Spec:** FINAL (2026-11-18), the core rules: the fourth test-writer review found no new behaviour, and
> its unpinned items are bit-level combinations, open below (§7's small-call stop). Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`SETTXT` programs the VDP for 40-column text from the work area, without touching VRAM:
- RG0SAV keeps only its bit 0; RG1SAV keeps bits 7-5 and 2-0, with bit 4 set and bit 3 clear (the
  text mode);
- RG2SAV-RG6SAV := TXTNAM / $400, TXTCOL / $40, TXTCGP / $800, TXTATR / $80, TXTPAT / $800, each
  cell shifted right (its low bits dropped); RG7SAV is not touched;
- the VDP registers R#0-R#6 get those values.

It leaves SCRMOD and the cells alone, returns A = the new RG6SAV, F = $00, BC = $0007, DE = 0, HL = $F3BD, and
interrupts **on**.

zerobas programs the VDP the same and leaves VRAM, SCRMOD and the interrupts as the VG-8020 does.
It stores the same shadow bytes (D-SETSHADOW, 2026-11-20, cbios-repack/vdp-calls.patch); and it returns the same registers
(D-SETREGS, 2026-11-20, cbios-repack/setregs-order.patch).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` of the XSET probe, run 4, on row `r`, both rows in
[`scratchpad/XSET_run4.out`](../../scratchpad/XSET_run4.out) (the two rows recorded the same bytes).
`probes/bios/spec/xset.asm` documents the presets, the table sets, the case table and the 112-byte
record:
- Before each case the probe sets, by hand: the 20 screen-table cells TXTNAM ($F3B3) .. MLTPAT
  ($F3D9) to one of six sets (0 the published defaults; 1 other aligned values; 2 other values,
  most with low bits set -- SETGRP's are all $3FFF; 3 every cell $FFFF; 4 and 5 cells of $4000,
  $8000 and $C000, bits 14 and 15 apart, each way round in most cells -- PAT for SETTXT /
  SETGRP and ATR for SETT32 / SETMLT are $C000 in both); RG0SAV / RG1SAV to $00 /
  $00, $FF / $FF, $5A / $A5, or (cases 48-63) apart: $01 / $00, $FE / $FF; RG2SAV-RG6SAV to $A5
  ($5A in cases 72-75); RG7SAV and SCRMOD to the case's ($00, $FF, $5A and 0-3 in cases 48-63, $A5 and
  $77 in the others);
  the VDP registers to $00 $80 $06 $80 $00 $36 $07 $F4; every VRAM byte to ((address low) XOR
  (address high) XOR $5A) OR the block number (address / $400), so the sixteen 1 KB blocks sum to
  sixteen different values. It reads the VDP status last, so no VDP interrupt is pending at the
  call.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (complemented in odd cases), A $A7, entry F and
  interrupts as the case lists them.
- After the call it records every register, the interrupt state (read twice: an interrupt accepted
  during the first read would show "off"), RG0SAV-RG7SAV, SCRMOD, the VDP
  registers R#0-R#7 as the VDP holds them (written into the record by the emulator's debugger,
  `@vdpsnap` in [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)), the 16-bit sums of
  VRAM's sixteen 1 KB blocks (read with R#1 := $80 first, so all 16 KB are addressed), and the 20
  screen-table cells.
- SETTXT: cases 00-11 and 48-51; SETT32: 12-23 and 52-55; SETGRP: 24-35 and 56-59; SETMLT: 36-47 and
  60-63; cell sets 4 and 5: 64 and 68 (SETTXT), 65 and 69 (SETT32), 66 and 70 (SETGRP), 67 and 71
  (SETMLT); the $5A preset: 72-75, one per call in that order.

## Open (not measured)

- **[A]** Cells and RG0SAV / RG1SAV values other than the measured sets: cell bits that always move
  together in them (walking-one values would pin each bit), RG1SAV only $00 / $FF / $A5 (its bits
  move in two groups), and the PAT (SETTXT / SETGRP) or ATR (SETT32 / SETMLT) cell with bits 14 and
  15 apart; RG2SAV-RG6SAV preset to $5A only with cell set 1, so a merge of the old shadow into the
  bits that set computes as 0 is not ruled out; VDP register presets other than the probe's one; entry F other than $00 and $FF, and entry A
  other than $A7.
- **[A]** VRAM writes that keep every 1 KB block's sum (the read-back compares sums, not bytes).
- **[A]** Whether the register writes are protected from an interrupt arriving during the call.
- **[A]** Entry with a VDP interrupt pending (the probe reads the status just before the call), and an
  interrupt arriving during it once the call has set R#1's interrupt bit (RG1SAV $FF, $A5).
- **[A]** Transient, repeated or reordered register writes (the snapshot shows the state after the
  call; a port trace would show each write).
- **[A]** Entry SCRMOD other than $77 and 0-3, RG7SAV other than $A5 / $00 / $FF / $5A, and BC, DE, HL,
  IX, IY other than their two marker sets; I/O state other than the VDP after the call.
- **[A]** The VDP's address latch and status register after the call; RAM other than RG0SAV-RG7SAV,
