# `SCANL` ($012F) — scan left for the PAINT border, and paint

> **Spec:** DRAFT 1 (2026-11-19), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`SCANL` is PAINT's left-hand scan. From the pixel left of the current position it counts the
non-border pixels leftwards, to the first border pixel (BDRATR) or X 0; HL returns the count and CLOC /
CMASK the leftmost counted pixel. Then it paints in ATRBYT, whatever B is, from there rightwards: in
SCREEN 2 HL + 8 pixels -- through the start pixel and the 7 after it -- as NSETCX sets them; in
SCREEN 3 the HL blocks only. B, DE, A and HL on entry are not used; A, F, BC and DE are left with
working values; interrupts are **on** after.

zerobas counts the same in all but one case measured, but paints only the HL pixels counted (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XQ rNN]**: case `NN` of the XGFX6 probe, run 4, on row `r`, both rows in
[`scratchpad/XGFX6_run4.out`](../../scratchpad/XGFX6_run4.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx6.asm` documents the presets, the case table and the 128-byte record:
- Before each case the probe sets, by hand: the screen-table cells to the published defaults; SCRMOD,
  CLOC, CMASK, ATRBYT ($0C for the scans) and BDRATR to the case's; RG0SAV-RG7SAV to $A5; the 41
  bytes $F92D-$F955 (the graphics work area) to a known pattern; every VRAM byte to ((address low)
  XOR (address high) XOR $5A) OR (address high AND $3C) -- which gives each pixel a colour the rules
  compute; the VDP registers to a preset with the display off. It reads the VDP status last.
- B, DE and HL ($2468 unless named) as the case lists them, C $57, IX $4321, IY $8765 (C, IX, IY
  complemented when bit 2 of the case number is set), A, F and the interrupt state as listed. After
  the call it records every register, the interrupt state (read twice), RG0SAV-RG7SAV, SCRMOD, the
  VDP registers, VRAM's 1 KB block sums and two windows, CLOC, CMASK, ATRBYT, BDRATR and the
  work-area bytes $F92D-$F933, $F942-$F954. FORCLR / BAKCLR / BDRCLR, recorded too, are not preset
  and not compared.
- SCREEN 2 cases start on pixel row Y 50 at X 96-111 (CLOC $0662 / $066A) unless named.
- SCANR: 09-17 (BDRATR 6, $E, 3, $F; B 0 / 1; DE 0, 3, $0100; F $FF and interrupts on), 18-19
  (SCREEN 3, block (24, 20)), 58-59 (SCREEN 3, near the right edge with B 1), 60 (X 254, no border to
  the edge), 61 (HL 0, A 0), 62 (a skip over 4 border pixels with DE 5, B 1).
- SCANL: 20-30 (as SCANR's 09-19), 31-38 (X 96-103, BDRATR 6), 39-43 (X 110, 105, 112, 103, 104 with
  BDRATR 6, $E, 3), 44-47 (DE 1, 8, $FFFF, 0), 48-52 (A 0 / $FF, HL 0 / $FFFF / 3), 53-55 (X 254 and
  248 with BDRATR $D -- runs to X 0 -- and X 0), 56-57 (SCREEN 3, blocks 24 / 25).
