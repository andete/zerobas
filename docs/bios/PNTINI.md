# `PNTINI` ($0129) — set the PAINT border colour

> **Spec:** FINAL (2026-11-19), the core rules: the second test-writer review found no new behaviour; the
> separating cases it asked for (run 10) all confirmed the rules. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`PNTINI` sets the colour PAINT stops at, BDRATR ($FCB2). In SCREEN 2 it ignores A and takes ATRBYT
(SCREEN 2's PAINT stops at the paint colour itself), returning A = ATRBYT with an AND's flags; in the
other modes it takes A, keeps it, and returns the flags of CP $10 then CCF -- the carry set for a
colour of 16 or more, which it stores all the same. Everything else is kept, the interrupt state
included.

zerobas does the same (D-PNTINIREGS, 2026-11-19: PNTINI is answered in the main ROM, not by the
sub-ROM paint tenant).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XQ rNN]**: case `NN` of the XGFX6 probe, run 10, on row `r`, both rows in
[`scratchpad/XGFX6_run10.out`](../../scratchpad/XGFX6_run10.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx6.asm` documents the presets, the case table and the 128-byte record:
- Before each case the probe sets, by hand: the screen-table cells to the published defaults; SCRMOD,
  CLOC ($0662), CMASK, ATRBYT ($07) and BDRATR ($33) to the case's; the 41 bytes $F92D-$F955 (the
  graphics work area) to a known pattern; every VRAM byte to ((address low) XOR (address high) XOR
  $5A) OR (address high AND $3C); the VDP registers to a preset with the display off. It reads the
  VDP status last.
- B $00, C $57, DE $9BDF, HL $2468 (RG0SAV-RG7SAV preset $A5), IX $4321, IY $8765 (C, IX, IY complemented when bit 2 of the case
  number is set), A, F and the interrupt state as the case lists them. After the call it records
  every register, the interrupt state (read twice), RG0SAV-RG7SAV, SCRMOD, the VDP registers, VRAM's
  1 KB block sums and two windows, CLOC, CMASK, ATRBYT, BDRATR and the work-area bytes $F92D-$F933,
  $F942-$F954.
- SCREEN 2 with A $05, $0F, $10, $FF (00-03); SCREEN 3 with A $05, $10, $FF (04-06); SCREEN 2 A $05
  and SCREEN 3 A $09 with F $FF and interrupts on (07, 08); SCREEN 2 with ATRBYT $00, $0A, $1A
  (67-69); SCRMOD 0 and 1 with A $05 (72, 73); SCREEN 3 with A $80 (76). FORCLR / BAKCLR / BDRCLR,
  recorded too, are not preset and not compared.
