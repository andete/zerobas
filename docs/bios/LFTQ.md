# `LFTQ` ($00F6) — room left in a queue

> **Spec:** FINAL (2026-11-19), the core rules: the last test-writer review found no new behaviour -- only
> combinations (open items below) and citations, fixed. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`LFTQ` returns how many bytes queue A can still take: HL = A = (get - ((put + 1) AND size)) AND size,
from the queue's QUETAB entry ($F959 + 6 x A: put, get, back flag, size, address) -- (get - put - 1)
mod 2^n for a size of 2^n - 1; the back flag is not used.
F is A's AND flags; B and C are left with (put + 1) AND size and get. Everything else is kept.

zerobas does all of it the same (since D-LFTQBC / D-LFTQSIZE, 2026-11-19).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.
