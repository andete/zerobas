# `CALPAT` ($0084) — the address of a sprite pattern

> **Spec:** DRAFT 1 (2026-11-18), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`CALPAT` returns in HL the VRAM address of sprite pattern A: PATBAS ($F926) plus A times the pattern
size, 8 bytes for 8 x 8 sprites and 32 for 16 x 16 (RG1SAV's bit 1, as [GSPSIZ](GSPSIZ.md) reads it).
It returns the size in A and the offset in DE. BC, IX, IY and the interrupt state are kept.

Its F: H, C and bits 5 / 3 from the addition; Z set exactly for 8 x 8 sprites; S and P/V clear,
whatever F was on entry.

zerobas returns the same address, A and DE; its F keeps the entry's S, Z and P/V (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XP rNN]**: case `NN` of the XSPR probe, run 1, on row `r`, both rows in
[`scratchpad/XSPR_run1.out`](../../scratchpad/XSPR_run1.out).
`probes/bios/spec/xspr.asm` documents the case table and the 20-byte record:
- Per case the probe sets RG1SAV ($F3E0), PATBAS ($F926) and ATRBAS ($F928) by hand, then BC $1357,
  DE $9BDF, HL $2468, IX $4321 and IY $8765 (all complemented in odd cases), the case's A, entry F
  ($00 in even cases, $FF in odd ones) and interrupt state, and calls.
- It records every register, the interrupt state, RG1SAV, PATBAS and ATRBAS after the call.
- CALPAT: cases 00-17 (A 0, 1, 7, $1F, $20, $7F, $FF with RG1SAV $E0 and $E2; then PATBAS $FFF8,
  $1234, $FFF0 with RG1SAV $E0-$E3). CALATR: 18-25 (A 0, 1, $1F, $20, $FF; ATRBAS $1B00, $FFFE, $ABCD,
  $1234). GSPSIZ: 26-33 (RG1SAV $E0, $E1, $E2, $E3, $00, $FF, $FD, $02).
- The VDP is not touched: these calls only compute from the work area.
