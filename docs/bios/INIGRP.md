# `INIGRP` ($0072) — set up the high-resolution graphics screen

> **Spec:** FINAL (2026-11-18), the core rules: the third test-writer review found no new behaviour; its
> items are combinations, open below (§7's small-call stop). Measured on the VG-8020, alone and with a disk
> interface, with the VDP's registers read back by the emulator's debugger after every call.

## Summary

`INIGRP` switches to the high-resolution graphics screen (SCREEN 2):
- the VDP is set up as [SETGRP](SETGRP.md) sets it from the GRP cells, with the display turned on
  (RG1SAV's bit 6), and the border colour R#7 / RG7SAV := BDRCLR;
- the name table counts 0-255 three times, then the colour table is filled with BAKCLR, then the
  pattern table is cleared (where tables overlap, the later write stays);
- the 32 sprite attribute entries are reset (Y 209, pattern numbers, FORCLR) -- the sprite patterns
  are left as they are;
- SCRMOD := 2, PATBAS / ATRBAS := GRPPAT / GRPATR.

It returns with interrupts **on**.

zerobas writes the same VRAM, overlapping tables included (D-INIGRPORDER, 2026-11-20, cbios-repack/setregs-order.patch), programs the VDP and stores RG0SAV and
the shadow bytes the same (D-SETSHADOW, 2026-11-20, cbios-repack/vdp-calls.patch); it returns other DE and HL (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XG rNN]**: case `NN` of the XINIG probe, run 3, on row `r`, both rows in
[`scratchpad/XINIG_run3.out`](../../scratchpad/XINIG_run3.out) (the two rows recorded the same bytes).
`probes/bios/spec/xinig.asm` documents the presets, the case table and the 128-byte record:
- Before each case the probe sets, by hand: the 20 screen-table cells to the published defaults
  (set 0), moved ones (set 1), unaligned ones (set 2: every GRP cell $3FFF; MLT $3BFF, $13FF, $17FF,
  $2F7F, $0FFF), every cell $FFFF (set 3), or set 4 (GRPNAM = GRPCOL = $2000; every MLT cell $3FFF); SCRMOD, RG1SAV, FORCLR / BAKCLR / BDRCLR to the case's; ATRBAS /
  PATBAS to $1111 / $2222 (neither a table the calls name); RG0SAV and RG2SAV-RG7SAV to $A5 ($00 in the set-4 cases); OLDSCR to
  $66; GRPACX / GRPACY to $1234 / $5678; the VDP registers to $00 $80 $06 $80 $00 $36 $07 $F4; every
  VRAM byte to ((address low) XOR (address high) XOR $5A) OR (address high AND $3C), so the
  sixteen 1 KB blocks sum to sixteen different values, none of them 0. It reads the VDP status last.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (complemented when bit 2 of the case number is
  set), A and entry F and the interrupt state as the case lists them; the interrupt state after is
  read twice (an interrupt accepted during the first read would show "off").
- After the call it records every register, RG0SAV-RG7SAV, SCRMOD, OLDSCR, PATBAS, ATRBAS, GRPACX /
  GRPACY, the colour cells, the VDP registers as the VDP holds them (written into the record by the
  emulator's debugger, `@vdpsnap` in [probes/bios/biosl_run.py](../../probes/bios/biosl_run.py)),
  the 16-bit sums of VRAM's sixteen 1 KB blocks (read with R#1 := $80 first) and three 16-byte VRAM
  windows.
- INIGRP: cases 00-05, 18, 19, 26-28, 36, 37; INIMLT: 06-11, 22-24, 29, 30, 38, 39; CHGMOD: 12-17,
  31-35 and 40 with A = 2, 3, 0, 1, 4, $FF, $7F, $80, $81, $FE, 2, 2; and set-ups called directly, for CHGMOD's comparison:
  00 (for 12), 06 (13), 20 INITXT (14), 21 INIT32 (15), 24 INIMLT (16, 31, 32), 25 INITXT (17, 33,
  34), 18 INIGRP (35), 28 INIGRP (40) -- the same cells, colours, SCRMOD, RG1SAV, entry F and
  interrupt state; entry A differs (CHGMOD's is the mode), and cases 12, 31 and 40 have the other
  marker set from their partners. Colours 15 / 4 / 7, $1A / $25 /
  $3C, 0 / 0 / 0, 5 / 6 / 8, $F0 / $0F / 0, 15 / $55 / 7, 15 / $F4 / 7, 15 / $25 / 7; RG1SAV $E0-$E3, $F0, $80, $A0;
  entry A $A7, $00, $FF; SCRMOD before 0-3, $77.

## Open (not measured)

- **[A]** An interrupt arriving during the call once it has set R#1's interrupt bit (the status is
  read just before the call).
- **[A]** RAM other than the cells recorded; VRAM outside the three windows beyond the block sums;
  cell, colour, RG1SAV and entry A values other than those measured; RG0SAV and RG2SAV-RG7SAV preset
  only to $A5 or $00, and the VDP registers only to the probe's one preset (display off).
- **[A]** The VDP status register after the call.
- **[A]** A name table (or colour table) that wraps past $3FFF with nothing written over it: in cases
  28 and 36 the wrapped tables are overwritten, so only the pattern and sprite tables' wrap is seen.
- **[A]** RG1SAV with bit 7 clear, or (INIGRP) bit 3 set, at entry.
- **[A]** The alternate registers and SP; the time it takes.
- **[A]** The CF-3300 (the second reference).
