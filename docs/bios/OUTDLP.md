# `OUTDLP` ($014D) — print a character as BASIC's printer output does

> **Spec:** FINAL (2026-11-18): the review's two unpinned rules (one graphic code, one NTMSXP value) measured in
> round 2; the rest open (§7's small-call stop). Measured on the VG-8020, alone and with a disk interface, with
> the emulator's printer logger plugged into the printer port, NTMSXP set to 0, $FF and $01.

## Summary

`OUTDLP` sends A to the printer the way `LPRINT` does, keeping the print head's column in LPTPOS
($F415). A TAB becomes spaces up to the next column that is a multiple of 8; CR sets the column to
0. A graphic character -- $01 followed by its code -- goes out as it is on an MSX printer (NTMSXP,
$F417, 0). On a printer that is not one (NTMSXP $FF or $01) the $01 is dropped and the code goes out
as one space ($41, $5F) or as it is ($7E). The $01 never counts as a column. A and the other
registers are kept (A is $20 for a code sent as a space).

zerobas does the same (D-OUTDLPGRAPH / D-OUTDLPF, 2026-11-19). The held $01 for a printer that is
not an MSX one is GRPHED ($FCA6) := 1 on both references and on zerobas (D-PAINTRAMCLASH,
[`scratchpad/OUTDLPHOLD_run1.out`](../../scratchpad/OUTDLPHOLD_run1.out)): the published graphic-header
flag, which CNVCHR and a GRP: channel's pending CHR$(1) share.

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** The XOUTDLP probe, run 2:
[`scratchpad/XOUTDLP_run2.out`](../../scratchpad/XOUTDLP_run2.out) (`N`),
[`scratchpad/XOUTDLP_run2d.out`](../../scratchpad/XOUTDLP_run2d.out) (`D`).
`probes/bios/spec/xoutdlp.asm` documents the sequences and the record. **[XO rP.NN]** is call `NN` of
pass `P`; **[XP r]** what the printer received on row `r`.
- The emulator's printer logger is plugged into the printer port and records every byte.
- One sequence, sent twice: `41 42 09 43 0D 0A 09 44 45 46 47 48 49 4A 09 78 01 41 85 FF 20 0D 0A`.
  Pass 0 with NTMSXP := 0 and entry F $00, pass 1 with NTMSXP := $FF and entry F $FF.
- A second sequence, `41 01 5F 09 42 01 7E 0D 0A` (two other graphic codes, a TAB right after a
  graphic character): pass 2 with NTMSXP := $01 and entry F $5A, pass 3 with NTMSXP := 0 and entry F
  $00. LPTPOS := 0 before each pass; interrupts off.
- BC, DE, HL, IX and IY carry markers. After each call the probe records LPTPOS, A and F.

## Differences from the reference

None measured: every rule holds on zerobas.

## Open (not measured)

- **[A]** A busy printer, and CTRL + STOP while OUTDLP waits (LPTOUT's abort: [LPTOUT](LPTOUT.md)).
- **[A]** Other control bytes ($00-$1F but TAB, CR, LF, $01), the graphic header before CR / TAB or
  at the end; a TAB past column 255.
- **[A]** Which codes after $01 become a space (only $41, $5F yes and $7E no measured); NTMSXP values
  other than 0, $01, $FF.
- **[A]** The register markers with a second set of values.
- **[A]** Entry F separated from NTMSXP (they change together per pass, though four pairs); LPTPOS
  other than 0 at the start.
- **[A]** The hooks; interrupts on; the alternate registers and SP; the CF-3300.
