# `LPTSTT` ($00A8) — the printer's status

> **Spec:** FINAL (2026-11-18), the core rule: one review found no unpinned rule and no new behaviour (§7's
> small-call stop). Measured on the VG-8020, alone and with a disk interface, with the
> emulator's printer logger plugged into the printer port, and with nothing plugged in.

## Summary

`LPTSTT` reports whether the printer is ready. With a printer ready it returns A $FF and Z clear
(F $BB: S, H, N and the carry set too); with nothing plugged in, A $00 and Z set (F $42) -- whatever A and F were on entry. It keeps
the other registers.

zerobas does all of the measured behaviour the same.

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** The XLPT probe, run 2:
[`scratchpad/XLPT_run2.out`](../../scratchpad/XLPT_run2.out) (`N`),
[`scratchpad/XLPT_run2d.out`](../../scratchpad/XLPT_run2d.out) (`D`).
`probes/bios/spec/xlpt.asm` documents the order and the record. **[XL rNN]** is LPTOUT with the byte
`NN`, **[XP r]** what the printer received on row `r`, **[XS rK]** the K-th LPTSTT (0 before the
bytes, 1 after).
- The emulator's printer logger is plugged into the printer port (the harness's `@printer`), and
  records every byte the printer receives.
- LPTSTT, then LPTOUT for every byte value 0-255 in order, then LPTSTT again; interrupts off.
- LPTOUT's entry A is the byte, entry F $00 for an even byte and $FF for an odd one. LPTSTT's entry
  A / F are $5A / $FF, then $A5 / $00. BC, DE, HL, IX and IY carry markers.

**[XN rK]**: the K-th call of the XLPT2 probe, run 1, with nothing plugged into the printer port:
[`scratchpad/XLPT2_run1.out`](../../scratchpad/XLPT2_run1.out) (`N`),
[`scratchpad/XLPT2_run1d.out`](../../scratchpad/XLPT2_run1d.out) (`D`) (`probes/bios/spec/xlpt2.asm`).
