# `STRTMS` ($0099) — start the background music

> **Spec:** FINAL (2026-11-19), the core rules: the last test-writer review found no new behaviour -- only
> combinations (open items below) and citations, fixed. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`STRTMS` starts the music PLAY has queued: when nothing plays (MUSICF $FB3F = 0) and PLYCNT
($FB40) is not 0, it takes one off PLYCNT, sets MUSICF := 7 and each voice's first word := 1; when music
is already playing, or there is nothing to play, it changes nothing. A, F and HL are left as the rules
say; the rest is kept.

zerobas does the same, the voices' first words and HL included (D-STRTMS, 2026-11-19).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` on row `r` -- cases 000-106 from the XSND1 probe, run 4
([`scratchpad/XSND1_run4.out`](../../scratchpad/XSND1_run4.out)), cases 107-134 from XSND1B, run 1
([`scratchpad/XSND1B_run1.out`](../../scratchpad/XSND1B_run1.out)), the same frame with a queue buffer
at $C000 and its own SET bits (the two rows recorded the same bytes,
apart from what the timer interrupt sets while interrupts are on: port C's keyboard row, and R15).
