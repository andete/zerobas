# `MAPXYC` ($0111) — turn coordinates into a graphics position

> **Spec:** FINAL (2026-11-18), the core rules: the third test-writer review found no new behaviour; its
> separating cases were measured (run 5) and every rule held (§7's small-call stop). Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`MAPXYC` turns the coordinates X (in C) and Y (in E) into the current graphics position, CLOC and
CMASK:
- in SCREEN 2, CLOC := GRPCGP + (Y AND $F8) x 32 + (X AND $F8) + (Y AND 7) and CMASK := $80 >> (X AND
  7): the pattern-table byte and bit of pixel (X, Y);
- in any other SCRMOD (SCREEN 3, and 0, 1, 4, 6, $82, $FF too), X and Y are multicolour block
  numbers, counted modulo 64: CLOC := MLTCGP + ((Y >> 3) AND 7) x 256 + ((X >> 1) AND 31) x 8 + (Y AND 7), CMASK := $F0
  for even X, $0F for odd.

HL ends equal to CLOC; A and F, and in SCREEN 2 D, carry intermediate values (the rules list them).
BC, IX, IY and the interrupt state are kept.

zerobas does all of it the same (since D-MAPXYCBASE / D-MAPXYCWRAP / D-MAPXYCMODE / D-MAPXYCF,
2026-11-19: its MAPXYC is basic/biosfnk.asm bios_mapxyc).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XG rNN]**: case `NN` of the XGFX1 probe, run 5, on row `r`, both rows in
[`scratchpad/XGFX1_run5.out`](../../scratchpad/XGFX1_run5.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx1.asm` documents the presets, the case table and the 28-byte record:
- Before each case the probe sets, by hand: CLOC ($F92A), CMASK ($F92C), GRPCGP ($F3CB) and MLTCGP
  ($F3D5) to the case's ($5A5A, $A5, $2000, $1000 in cases 00-42), ATRBYT ($F3F2) to $77, ASPCT1 /
  ASPCT2 ($F40B / $F40D) to $1234 / $5678 ($0100 / $00C0 in case 12), SCRMOD to the case's.
- IX $4321 and IY $8765 (complemented when bit 2 of the case number is set); A, F, BC, DE, HL and
  the interrupt state as the case lists them. After the call it records every register, the
  interrupt state (read twice: an interrupt accepted during the first read would show "off"), and
  CLOC, CMASK, ATRBYT, ASPCT1 / ASPCT2, SCRMOD, GRPCGP and MLTCGP.
- FETCHC: cases 00-01, 43 (CLOC $1234 / CMASK $40); STOREC: 02-04, 44; SETATR: 05-10 (A $00, $05,
  $0F, $10, $FF, $80), 45 ($20); GTASPC: 11-12, 46; cases 43-46 with other BC / DE / HL / A / F.
  MAPXYC: 13-22 in SCREEN 2 (X, Y: 0,0; 7,0; 8,0; 9,1; 255,191; 100,50; 0,8; 256,0; 0,192;
  $FFFF,$FFFF); 23-29 and 32-42 in SCREEN 3 (block numbers: 0,0; 3,0; 4,0; 255,191; 100,50; 4,4; 0,8;
  X 31, 32, 63, 64, 127; Y 7, 63, 64, 127, 128; 65,65); 30-31 in SCREEN 1 and 0; 47-58 with GRPCGP
  $0000 / $1804 / $20F8 and MLTCGP $0000 / $0B00 / $0300 / $2800 / $1100, entry A $00 / $FF / $5A,
  SCRMOD 4 and $FF, a SCREEN 3 case with D $01 (54) and one with B $11, D $22 (58), a SCREEN 2 case
  with Y $0100; 59-65 with SCRMOD 6 and $82, GRPCGP $0800 / $F000 / $3800 (base additions that carry
  out of bit 11 or 15, and a CLOC of $4000), MLTCGP $10F8 and $3C00; 66-80: SCREEN 2 X 2, 3, 5,
  6; MLTCGP $F900 (a carry out of bit 15), GRPCGP $07F8 / $FFF8 / $2004 (carries from the low byte,
  and A 0 with CLOC's low byte $04); X 8 with D $01; SCRMOD $0A and $42; CLOC $0000 with CMASK $00 /
  $FF preset; X $0100 with CMASK $00 / $FF preset and A $00.
- The probe does not look at the VDP.
