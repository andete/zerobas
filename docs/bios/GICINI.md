# `GICINI` ($0090) — initialise the PSG and the PLAY queues

> **Spec:** FINAL (2026-11-19), the core rules: the last test-writer review found no new behaviour -- only
> combinations (open items below) and citations, fixed. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`GICINI` resets the sound state: PSG R7 := $B8 (tones on, noise off, port A in, port B out), the
volumes R8-R10 := 0; queues 0-2 rewritten (put, get, back flag := 0, size $7F, address VOICAQ /
VOICBQ / VOICCQ -- whatever they held); MUSICF and PLYCNT := 0;
each 37-byte voice buffer from VCBA ($FB41) cleared, bytes 15-19 set to $04 $04 $78 $88 $FF. It keeps
the registers and returns with interrupts **on**.

zerobas resets the PSG and the queues the same, but not the voice buffers (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` on row `r` -- cases 000-106 from the XSND1 probe, run 4
([`scratchpad/XSND1_run4.out`](../../scratchpad/XSND1_run4.out)), cases 107-134 from XSND1B, run 1
([`scratchpad/XSND1B_run1.out`](../../scratchpad/XSND1B_run1.out)), the same frame with a queue buffer
at $C000 and its own SET bits (the two rows recorded the same bytes,
apart from what the timer interrupt sets while interrupts are on: port C's keyboard row, and R15).
`probes/bios/spec/xsnd1.asm` documents the presets, the case table and the 80-byte record:
- Before each case the probe sets, by hand: PSG registers R0-R13 to $A1 $02 $B3 $04 $C5 $06 $17 $B8
  $09 $0A $0B $5C $1D $0E (R7 $BF in case 72) and R15 to $CF, through the PSG's ports; the PPI's port C to $50 (or $D0:
  bit 7 the 1-bit sound); QUETAB ($F959), QUEBAK, QUEUEN ($FB3E), VOICEN ($FB38), MUSICF, PLYCNT to
  one of six sets; the queue buffers VOICAQ / VOICBQ / VOICCQ ($F975-$FAF4), queue 3's buffer at
  $E800 (the probe's own RAM: RS2IQ, $FAF5-$FB34, is left alone -- the disk interface's VG-8020 keeps
  something there, and overwriting it stops that machine) and the voice buffers VCBA-VCBC ($FB41-$FBAF)
  to (address low) XOR $A5.
- BC $1357, DE, HL ($2468 unless named), IX $4321, IY $8765 (IX / IY complemented when bit 2 of the
  case number is set), A, F and the interrupt state as the case lists them. After the call it
  records every register, the interrupt state (read twice), PSG R0-R15 (read through the ports),
  port C, QUETAB + QUEBAK, QUEUEN / VOICEN / MUSICF / PLYCNT and 16 RAM bytes from a case's window.
- WRTPSG 00-08 (A 0 / 7 / 8 / 13 / 15 / 14 / 16 / $40, E as listed; A 1 with F $FF and interrupts on);
  RDPSG 09-17 (the same registers; A 3 with F $FF and interrupts on); CHGSND 18-24 (A 0 / 1 with bit 7
  0 and 1; $FF, $80, 2); LFTQ 25-36 (queues 0-3 in each of the three sets); PUTQ 37-46 (E $5A: the
  four queues in set 0 and set 1, queues 0 and 3 in set 2 -- free, and full where (put + 1) AND size
  is get); GETVCP 47-50 (A 0-3); GETVC2 51-57 (L 0, 5, 36 with VOICEN 0; 0, 7 with 1; 0, 36 with 2);
  GICINI 58-66 and 72 (windows over the voice buffers $FB41-$FBB0, the queue buffer $F975 and $FB30;
  sets 0 / 1 / 2; R7 $BF); STRTMS 67-71 (MUSICF / PLYCNT 0 / 0, 7 / 3, 0 / 0, 0 / 3, 7 / 0); BEEP 73,
  74 (interrupts off / on).
- Round 4: CHGSND, LFTQ, PUTQ, GETVCP, GETVC2 with F $FF, interrupts on and port C bit 7 set (75-79);
  WRTPSG / RDPSG with port C bit 7 set (80, 81); PUTQ stores whose put wraps to 0 (82, 84) or whose
  address + put carries into the high byte (83), full at a wrap with the window on the queue's base
  (85, 86), full with BC $2468 (87); LFTQ windows over queues 1-3 (88-90), a size of $7E (91), queue 0
  of set 5 (92), queue 4 (93: QUEBAK and the buffer's first bytes as an entry); GETVCP A 4 / 6 and
  windows over voices 0 / 2 (94-97); GETVC2 with L $C0, H $00 / $FF, VOICEN 3, a window over voice 1
  (98-102); WRTPSG R7 := $BF / $3F and R15 := $80 / $C0 (103-106).
- XSND1B (107-134): GICINI entered with interrupts on, F $FF and port C bit 7 set, with set 5's queue
  sizes / addresses, windows over the queue buffers' ends and over $FB30 (now preset), R7 $3F with
  volumes $13-$15 (107-112, 122); STRTMS with interrupts on, MUSICF 3 / PLYCNT 5 with F $FF, PLYCNT 1,
  windows over voices B and C (113-117); BEEP with R7 $BF and port C bit 7, windows over voices A-C,
  other A / F / BC / DE with R7 $3F (118-121); CHGSND A 0 with F $FF and interrupts on, and with port
  C $2F (123-125); GETVCP A 0 with F $FF and A $21 (126, 127); GETVC2 VOICEN 1 with F $FF (128); PUTQ
  full with F $FF and interrupts on (129), stores into a queue at $C000 (130) and with size $7E (131,
  132); LFTQ with size $7E (133, 134).
