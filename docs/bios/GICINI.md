# `GICINI` ($0090) — initialise the PSG and the PLAY queues

> **Spec:** DRAFT 1 (2026-11-19), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`GICINI` resets the sound state: PSG R7 := $B8 (tones on, noise off, port A in, port B out), the
volumes R8-R10 := 0; queues 0-2 emptied (put, get, back flag := 0, size $7F); MUSICF and PLYCNT := 0;
each 37-byte voice buffer from VCBA ($FB41) cleared, bytes 15-19 set to $04 $04 $78 $88 $FF. It keeps
the registers and returns with interrupts **on**.

zerobas resets the PSG and the queues the same, but not the voice buffers (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` of the XSND1 probe, run 3, on row `r`, both rows in
[`scratchpad/XSND1_run3.out`](../../scratchpad/XSND1_run3.out) (the two rows recorded the same bytes,
apart from the keyboard-row bits and R15 the timer interrupt sets while interrupts are on).
`probes/bios/spec/xsnd1.asm` documents the presets, the case table and the 80-byte record:
- Before each case the probe sets, by hand: PSG registers R0-R13 to $A1 $02 $B3 $04 $C5 $06 $17 $B8
  $09 $0A $0B $5C $1D $0E (R7 $BF in case 72) and R15 to $CF, through the PSG's ports; the PPI's port C to $50 (or $D0:
  bit 7 the 1-bit sound); QUETAB ($F959), QUEBAK, QUEUEN ($FB3E), VOICEN ($FB38), MUSICF, PLYCNT to
  one of five sets; the queue buffers VOICAQ / VOICBQ / VOICCQ ($F975-$FAF4), queue 3's buffer at
  $DF00 (the probe's own RAM: RS2IQ, $FAF5-$FB34, is left alone -- the disk interface's VG-8020 keeps
  something there, and overwriting it stops that machine) and the voice buffers VCBA-VCBC ($FB41-$FBAF)
  to (address low) XOR $A5.
- BC $1357, DE, HL ($2468 unless named), IX $4321, IY $8765 (IX / IY complemented when bit 2 of the
  case number is set), A, F and the interrupt state as the case lists them. After the call it
  records every register, the interrupt state (read twice), PSG R0-R15 (read through the ports),
  port C, QUETAB + QUEBAK, QUEUEN / VOICEN / MUSICF / PLYCNT and 16 RAM bytes from a case's window.
- WRTPSG 00-08 (A 0 / 7 / 8 / 13 / 15 / 14 / 16 / $40, E as listed; A 1 with F $FF and interrupts on);
  RDPSG 09-17 (the same registers; A 3 with F $FF and interrupts on); CHGSND 18-24 (A 0 / 1 with bit 7
  0 and 1; $FF, $80, 2); LFTQ 25-36 (queues 0-3 in each of the three sets); PUTQ 37-46 (E $5A: the
  four queues in set 0 and set 1, queues 0 and 3 in set 2 -- free, and full where (put + 1) AND size
  is get); GETVCP 47-50 (A 0-3); GETVC2 51-57 (L 0, 5, 36 with VOICEN 0; 0, 7 with 1; 0, 36 with 2);
  GICINI 58-66 and 72 (windows over the voice buffers $FB41-$FBB0, the queue buffer $F975 and $FB30;
  sets 0 / 1 / 2; R7 $BF); STRTMS 67-71 (MUSICF / PLYCNT 0 / 0, 7 / 3, 0 / 0, 0 / 3, 7 / 0); BEEP 73,
  74 (interrupts off / on).
