# `LPTOUT` ($00A5) — send a byte to the printer

> **Spec:** FINAL (2026-11-18): the review's one unmeasured behaviour (the abort) measured in round 3; the rest
> open (§7's small-call stop). Measured on the VG-8020, alone and with a disk interface, with the
> emulator's printer logger plugged into the printer port.

## Summary

`LPTOUT` sends A to the printer, as it is: every byte value goes out unchanged, and nothing is
added. It returns with the carry clear (sent), A kept, and the other registers kept; F is an AND's
flags on A. With no printer ready it waits; CTRL + STOP ends the wait with the carry set (aborted),
F $01, A and the registers kept.

zerobas does all of the measured behaviour the same, apart from the rest of F after an abort (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** The XLPT probe, run 2:
[`scratchpad/XLPT_run2.out`](../../scratchpad/XLPT_run2.out) (`N`),
[`scratchpad/XLPT_run2d.out`](../../scratchpad/XLPT_run2d.out) (`D`).
`probes/bios/spec/xlpt.asm` documents the order and the record. **[XL rNN]** is LPTOUT with the byte
`NN`, **[XP r]** what the printer received on row `r`.
- The emulator's printer logger is plugged into the printer port (the harness's `@printer`), and
  records every byte the printer receives.
- LPTSTT, then LPTOUT for every byte value 0-255 in order, then LPTSTT again; interrupts off.
- LPTOUT's entry A is the byte, entry F $00 for an even byte and $FF for an odd one. LPTSTT's entry
  A / F are $5A / $FF, then $A5 / $00. BC, DE, HL, IX and IY carry markers.

**[XA r]**: the XLPT3 probe, run 1 (`probes/bios/spec/xlpt3.asm`):
[`scratchpad/XLPT3_run1.out`](../../scratchpad/XLPT3_run1.out) (`N`),
[`scratchpad/XLPT3_run1d.out`](../../scratchpad/XLPT3_run1d.out) (`D`). Nothing is plugged into the
printer port; the probe calls LPTOUT with A $41, F $00, and the harness holds CTRL + STOP (key matrix
row 6 bit 1, row 7 bit 4) for 0.3 s while it waits.
