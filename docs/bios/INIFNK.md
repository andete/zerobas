# `INIFNK` ($003E) — set the default function-key strings

> **Spec:** FINAL (2026-11-18), the core rule: the confirming pass was CLEAN (docs/spec-method.md
> §7); the open items stay [A] and do not hold up the fixes. After one earlier test-writer review. Measured on the Philips VG-8020 from
> garbage, from several starting states, with every register and the whole work area read.

## Summary

`INIFNK` writes the ten default function-key strings into FNKSTR ($F87F, 10 × 16 bytes), every byte
of every slot, whatever was there. It does not redraw the key line, and changes no other cell of
the work area. It keeps A, IX and IY, and returns with interrupts disabled
when entered so.

zerobas writes the same strings, on the diskless and the disk machine alike. Its registers on return
differ, and it returns with interrupts enabled (D-TEXTAF). Separately, at cartridge INIT FNKSTR
already holds the defaults on both machines (R-F-BOOT): that is the boot's job, not INIFNK's.

## The specification

Reference: the Philips VG-8020's main BIOS. Ours: the C-BIOS repack. The strings are what the key
line shows ([DSPFNK.md](DSPFNK.md)).

**Evidence.** **[XF 1]**: the XFNK2 probe, [`scratchpad/XFNK2_run1.out`](../../scratchpad/XFNK2_run1.out):
- FNKSTR is filled with $5A garbage, and the bytes either side of it with $A5;
- A / F are $5A / $FF on entry.

**[XF3 row n]**: case `n` of XFNK3 on the diskless and the disk row,
[`scratchpad/XFNK3_run2.out`](../../scratchpad/XFNK3_run2.out). `probes/bios/spec/xfnk3.asm`
documents it. It answers the first review's findings:
- three starting states: all $00; a per-key mix of $00, $5A, 16 letters with no 0, and the default
  "list " with $5A padding; all $5A;
- three entry A / F values, every other register loaded with garbage, interrupts off;
- the key line on in one case, with its row overwritten so a redraw would show;
- the whole work area $F380–$FFFF compared before and after. Run 2 compares right after the call:
  run 1 compared after its own VRAM reads, which let an interrupt run on the reference (the
  confirming pass found this).

**[XB 1]**: the earlier XFNK ([`XFNK_run1.out`](../../scratchpad/XFNK_run1.out)), FNKSTR as a
cartridge's INIT finds it. It called INIFNK on that boot-time FNKSTR, which on the reference
already held the defaults, so it is evidence only for the boot state.

## Open (not measured)

- **[A]** The alternate registers on return; F's bits 5 / 3 for other entry values.
- **[A]** INIFNK entered with interrupts ENABLED (only entry with them disabled measured); IX / IY
  with one value each; RAM below $F380 and the stack.
- **[A]** S / Z / C passing through one at a time (entry F only $00 / $FF); the boot-time FNKSTR on
  the disk row (XFNK ran diskless only); a work area with a second background pattern (a write of
  an unchanged value is invisible to the snapshot).
