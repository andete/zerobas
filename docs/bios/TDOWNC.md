# `TDOWNC` ($010B) — move the graphics position down, checking the edge

> **Spec:** FINAL (2026-11-19), the core rules: the fourth test-writer review found no new behaviour; the
> separating cases it asked for (run 7) all confirmed the rules. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`TDOWNC` moves down as [DOWNC](DOWNC.md) does, but stops at the bottom: CLOC and CMASK kept, A = 0,
carry set. The bottom is, in SCREEN 2, CLOC AND 7 = 7 with CLOC GRPCGP + $1700 or more (unsigned:
a CLOC below the table moves on); in SCREEN 3, CLOC AND 7 = 7 with a high byte of 5 or more -- absolute again, so with MLTCGP $1000
it stops at every block row's last line.

zerobas does all of it the same (SCREEN 2's edge since D-TEDGE, 2026-11-19).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XM rNNN]**: case `NNN` of the XGFX2 probe, run 7, on row `r`, both rows in
[`scratchpad/XGFX2_run7.out`](../../scratchpad/XGFX2_run7.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx2.asm` documents the presets, the case table and the 28-byte record:
- Before each case the probe sets, by hand: CLOC ($F92A) and CMASK ($F92C) -- mostly a pixel's
  position as [MAPXYC](MAPXYC.md) gives it, the exceptions listed below -- GRPCGP ($F3CB), MLTCGP ($F3D5) and SCRMOD to the case's, ATRBYT to
  $77, ASPCT1 / ASPCT2 to $1234 / $5678.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (IX / IY complemented when bit 2 of the case
  number is set), A $A7, entry F $00 / $FF and interrupts off / on by case. After the call it records
  every register, the interrupt state (read twice), CLOC, CMASK and the other cells.
- Cases 000-125: each of the six calls from 11 SCREEN 2 positions (corners, the 8-pixel and
  character-row edges, a middle point; GRPCGP $2000) and 10 SCREEN 3 positions (MLTCGP $1000), in
  the order RIGHTC, LEFTC, UPC, TUPC, DOWNC, TDOWNC. Cases 126-251: TUPC, then TDOWNC, at the lines
  around each character row's top and bottom, with GRPCGP $0000 / $2000 / $1800 (SCREEN 2) and
  MLTCGP / GRPCGP $0000 / $2000, $1000 / $2000, $1000 / $0000, $0800 / $1800 (SCREEN 3). Cases
  252-276: TUPC / TDOWNC in SCREEN 2 at character rows 7, 8, 15, 16 (GRPCGP $0000 and $2000) and with
  GRPCGP $2100 (TUPC and TDOWNC) and $2004 (TUPC), entry A $00 / $FF and (TDOWNC, 263-270) other BC / DE / HL; TDOWNC in SCREEN 3 at high bytes
  6, 7 and $85; RIGHTC / LEFTC in SCREEN 3 with CMASK $F1 / $1F (not a pixel's mask).
- Cases 277-302: TDOWNC with GRPCGP $2004; TUPC in SCREEN 3 at CLOC $0020 with MLTCGP $1000 / $0800,
  and at $2020 / $8020; TUPC with GRPCGP $2004 at CLOC $2100 / $2000; UPC at CLOC $0020 / $0008 and
  LEFTC at $0000 (wrapping); RIGHTC with SCREEN 3 CMASK $1F / $8F / $FF and LEFTC with $80 / $F1;
  RIGHTC / LEFTC with SCREEN 2 CMASK $03; the four plain moves with entry A $FF, F $FF, interrupts on
  and other BC / DE / HL; a TDOWNC stop with entry A $FF; DOWNC from $FFFF and RIGHTC from $FFFC.
- Cases 303-323: TDOWNC at CLOC $36FF (GRPCGP $2000), $3707 (GRPCGP $2008, $2005), $0F07 (GRPCGP
  $2000), $8007, $9707, $96FF (GRPCGP $0000), and in SCREEN 3 at $04FF (MLTCGP $0000); TUPC at $2100
  with GRPCGP $2001-$2003, at $0008 (GRPCGP $2000), $8000 and $8100 (GRPCGP $0000), and in SCREEN 3
  at $00F8 (MLTCGP $0000); RIGHTC / LEFTC with SCREEN 3 CMASK $70 / $4F; LEFTC with SCREEN 2 CMASK
  $C0 / $81.
- Cases 324-333: UPC at $2663 (A 3); TDOWNC at $3707 with GRPCGP $2007 / $2006; TDOWNC, DOWNC at
  $2007 and UPC at $2008 with GRPCGP $2004; LEFTC with SCREEN 3 CMASK $8F / $FF; TUPC moving and
  stopping with BC / DE / HL $ECA8 / $6420 / $DB97.
- Not positions MAPXYC gives: a CMASK that is not a pixel's (275, 276, 285-289, 294, 295, 310-315,
  330, 331); CLOC off GRPCGP's grid or outside the table (261, 277-279, 290, 291, 304-306, 309,
  316-329); SCREEN 3 CLOC outside the table (272-274, 280-282, 292, 293); CLOC $FFFF / $FFFC (301,
  302).
- Case 255 enters with ASPCT1 / ASPCT2 $0100 / $00C0 (the probe's marker for that case number).
- The rule tables count each case once per row (N and D).
