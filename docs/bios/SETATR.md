# `SETATR` ($011A) — set the graphics colour

> **Spec:** DRAFT 1 (2026-11-19), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`SETATR` sets the colour the graphics calls draw with: for A 0-15, ATRBYT ($F3F2) := A, carry clear;
for A of 16 or more, ATRBYT is kept and the carry set. The rest of F is what CP $10 followed by CCF
leaves. A and the other registers, and the interrupt state, are kept.

zerobas does all of it the same.

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XG rNN]**: case `NN` of the XGFX1 probe, run 2, on row `r`, both rows in
[`scratchpad/XGFX1_run2.out`](../../scratchpad/XGFX1_run2.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx1.asm` documents the presets, the case table and the 24-byte record:
- Before each case the probe sets, by hand: CLOC ($F92A) to $5A5A, CMASK ($F92C) to $A5, ATRBYT
  ($F3F2) to $77, ASPCT1 / ASPCT2 ($F40B / $F40D) to $1234 / $5678 ($0100 / $00C0 in case 12),
  GRPCGP ($F3CB) to $2000, MLTCGP ($F3D5) to $1000, SCRMOD to the case's.
- IX $4321 and IY $8765 (complemented when bit 2 of the case number is set); A, F, BC, DE, HL and
  the interrupt state as the case lists them. After the call it records every register, the
  interrupt state (read twice: an interrupt accepted during the first read would show "off"), and
  the work-area cells.
- FETCHC: cases 00-01; STOREC: 02-04; SETATR: 05-10 (A $00, $05, $0F, $10, $FF, $80); GTASPC: 11-12;
  MAPXYC: 13-22 in SCREEN 2 (X, Y: 0,0; 7,0; 8,0; 9,1; 255,191; 100,50; 0,8; 256,0; 0,192;
  $FFFF,$FFFF), 23-29 and 32-42 in SCREEN 3 (0-255 by 0-191, and X 31, 32, 63, 64, 127, Y 7, 63, 64,
  127, 128), 30-31 in SCREEN 1 and 0.
- None of these calls touches the VDP; the probe does not look at it.
