# `BREAKX` ($00B7) — check CTRL+STOP directly

> **Spec:** DRAFT 1 (2026-11-19), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`BREAKX` reads the key matrix directly and sets the carry when CTRL and STOP are both pressed. Then
it also empties the key buffer (GETPNT := PUTPNT) and marks STOP in OLDKEY's row 7. A is left with a
working value; the interrupt state and the rest are kept.

zerobas sets the carry the same, but does not empty the key buffer (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XI rNN]**: case `NN` of the XINP1 probe, run 1, on row `r`, both rows in
[`scratchpad/XINP1_run1.out`](../../scratchpad/XINP1_run1.out) (the two rows recorded the same bytes,
apart from what the timer interrupt's key scan writes while interrupts are on).
`probes/bios/spec/xinp1.asm` documents the presets, the case table and the 48-byte record:
- Before each case the debugger sets the keyboard matrix (`@keyset`, probes/bios/biosl_run.py: the
  emulator's key matrix, as a person pressing keys -- no key, or the case's one or two); the probe
  sets PUTPNT / GETPNT to KEYBUF + 5 / + 2 (three keys queued), INTFLG to the case's, CAPST $00,
  TRGFLG $F1, NEWKEY / OLDKEY $FF x 11, the PPI's port C to $50 and PSG R15 to $CF. Nothing is plugged
  into the joystick ports.
- BC $1357, DE $9BDF, HL $2468, IX $4321, IY $8765 (IX / IY complemented when bit 2 of the case number
  is set), A, F and the interrupt state as the case lists them. After the call it records every
  register, the interrupt state (read twice), port C, PSG R14 / R15, PUTPNT, GETPNT, INTFLG, CAPST,
  TRGFLG, NEWKEY and OLDKEY.
- When a call returns with interrupts on, the timer interrupt may scan the keys before the probe
  reads: the cells that scan writes (PUTPNT, GETPNT, NEWKEY, OLDKEY, TRGFLG, R15, port C's low nibble)
  are not evidence in those cases.
- SNSMAT 00-12 (rows 0-10 with a key, row 8 with none / four, A 11 / $FF); KILBUF 13, 14; CHGCAP 15-19
  (A 0, 1, $FF, $80); GTSTCK 20-36 (A 0 with the cursor keys, A 1-3); GTTRIG 37-44 (A 0 without / with
  the space bar, A 1-5); BREAKX 45-49 (no key, CTRL+STOP, STOP, CTRL); ISCNTC 50, 51; CKCNTC 52, 53;
  GTPAD 54-59 (A 0-4, 7); GTPDL 60-62 (A 1, 2, 12). The last case of most groups enters with F $FF and
  interrupts on.
