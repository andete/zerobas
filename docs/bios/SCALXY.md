# `SCALXY` ($010E) — clip a graphics coordinate

> **Spec:** DRAFT 1 (2026-11-19), before review. Measured on the VG-8020, alone and with a disk
> interface.

## Summary

`SCALXY` clips the graphics coordinate in BC (X) and DE (Y) to the screen: a negative value (bit 15
set) becomes 0, X above 255 becomes 255, Y above 191 becomes 191. In any mode but SCREEN 2 it then
divides both by 4, giving SCREEN 3's block numbers. The carry is set, and A = $80, when nothing was
clipped; the carry is clear and A = 0 when either was. HL, IX, IY, the interrupt state and the work
area are kept.

zerobas clips the same, but divides only in SCREEN 3 and returns other flags there (below).

## The specification

References: the Philips VG-8020's main BIOS, alone (row `N`) and with an NMS 1200 disk interface
(row `D`). Ours: the C-BIOS repack, diskless on row `N`, the disk build on `D`.

**Evidence.** **[XS rNN]**: case `NN` of the XGFX4 probe, run 1, on row `r`, both rows in
[`scratchpad/XGFX4_run1.out`](../../scratchpad/XGFX4_run1.out) (the two rows recorded the same bytes).
`probes/bios/spec/xgfx4.asm` documents the presets, the case table and the 28-byte record:
- Before each case the probe sets, by hand: CLOC ($F92A) $5A5A, CMASK ($F92C) $A5, GRPCGP ($F3CB)
  $2000, MLTCGP ($F3D5) $1000, ATRBYT ($F3F2) $77, ASPCT1 / ASPCT2 ($F40B / $F40D) $1234 / $5678,
  SCRMOD to the case's.
- IX $4321 and IY $8765 (complemented when bit 2 of the case number is set); A ($00 / $A7), F ($00 /
  $FF), BC, DE, HL ($2468 / $FFFF) and the interrupt state as the case lists them. After the call it
  records every register, the interrupt state (read twice), and the cells above.
- X, Y: (100, 50), (0, 0), (255, 191), (256, 191), (255, 192), (256, 192), ($FFFF, 50), (100,
  $FFFF), ($8000, $8000), ($7FFF, $7FFF), (300, 300), ($FF00, 50), (511, 0), (128, 192): cases 00-13
  in SCREEN 2, 14-27 in SCREEN 3; (100, 50) and (300, 300) in SCREEN 0 (28, 29) and 1 (30, 31).
- The probe does not look at the VDP.
