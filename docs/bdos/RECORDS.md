# The BDOS's record functions through `$F37D`

> **Spec:** DRAFT 1 (2026-11-22), one measured round on two references, no review yet.
> One page for the record functions sharing one probe: WRSEQ ($15), RDSEQ ($14), SETRND ($24), RDRND ($21),
> WRRND ($22). RDBLK / WRBLK / WRZER are not on it.

## Summary

Through the disk ROM's BDOS entry at $F37D, on a file made on the empty disk:

- **WRSEQ** writes the DTA's 128 bytes at the FCB's current record (+32) and advances it; **RDSEQ** reads
  the record there into the DTA and advances it, and answers 1 past the end (the DTA left).
- **SETRND** sets the random record (+33 .. +35) from the position.
- **RDRND** / **WRRND** read / write the record the random record names, and set the current record to it;
  a write past the end grows the file to that record. A record never written reads back undefined bytes.
- A write clears bit 6 of +24 and sets the cluster words (+26 / +28).

zerobas reads and writes the same records and fills the FCB the same; only its flags differ (D-F37DREGS).
(Writing at the current record past the first extent, and the extent byte, differ: [FILES](FILES.md),
D-FCBEXTENT.)

## The specification

References: the Philips VG-8020 with an NMS 1200 disk interface (row `D`) AND the National CF-3300
(row `C`). Ours: zerobas's disk build.

**Evidence.** **[XR rNN]**: case `NN` on row `r` of the XBREC1 probe -- run 1 for row D
([`scratchpad/XBREC1_run1.out`](../../scratchpad/XBREC1_run1.out), `--row disk`), run 2 for row C
([`scratchpad/XBREC1_run2.out`](../../scratchpad/XBREC1_run2.out), `--row cf3300`).
`probes/bios/spec/xbrec1.asm` documents the cases (SETDTA, FMAKE R.TXT, WRSEQ twice, FCLOSE, FOPEN, RDSEQ
three times, SETRND, RDRND 0, WRRND 5, RDRND 5, RDRND 3, FCLOSE, FSIZE) and the record (XBFILE4's: A, F,
the FCB, the DTA's first 13 bytes); the DTA's 128 bytes hold $40 + the case number before each case.
