# The BDOS's record functions through `$F37D`

> **Spec:** FINAL (2026-11-22), the core rules: review pass 2's rule pairs were answered by round 3 with no new
> reference behaviour (SETRND's 1 on an empty and a 6-record file, RR and CR kept, FSIZE's fields); the rest are
> combinations, now [A] (docs/spec-method.md §7, the small-call stop). Three measured rounds on two references
> (scratchpad/BREC_review1.md, BREC_review2.md).
> One page for the record functions sharing one probe: WRSEQ ($15), RDSEQ ($14), SETRND ($24), RDRND ($21),
> WRRND ($22). RDBLK / WRBLK / WRZER are not on it.

## Summary

Through the disk ROM's BDOS entry at $F37D, on a file made on the empty disk:

- **WRSEQ** writes the DTA's 128 bytes, in order, at the FCB's current record (+32) and advances it;
  **RDSEQ** reads the record there into the DTA and advances it, and answers 1 past the end of the file's
  SIZE (the DTA and CR left) -- +15 does not end it.
- **SETRND** sets the random record (+33 .. +35) to 1 -- whatever the position (CR 0, 1, 2, 5) and the size
  (0, 2 and 6 records) -- and leaves +36. WRSEQ and RDSEQ leave the random record.
- **RDRND** / **WRRND** read / write the record the random record names, and set the current record to it;
  RDRND past the end answers 1; WRRND past the end grows the file to that record, inside it overwrites
  (the size kept). A record never written reads back undefined bytes.
- **FOPEN** sets +15 to the records in the extent; **FSIZE** writes +33 .. +35 and nothing else of the
  FCB (+36 left). WRSEQ and WRRND leave +15.
- WRSEQ after FMAKE clears bit 6 of +24 and sets the cluster words (+26 / +28).

zerobas reads and writes the same records and fills the FCB the same; its SETRND clears +36
(D-SETRNDR36), and its flags and SETDTA's A differ (D-F37DREGS).
(Writing at the current record past the first extent, and the extent byte, differ: [FILES](FILES.md),
D-FCBEXTENT.)

## The specification

References: the Philips VG-8020 with an NMS 1200 disk interface (row `D`) AND the National CF-3300
(row `C`). Ours: zerobas's disk build.

**Evidence.** **[XR rNN]**: case `NN` on row `r` of the XBREC1 probe -- run 1 for row D

the 6-record file over $FF at +34 .. +36, WRSEQ after SETRND, RDSEQ at CR 10, FSIZE on FOPEN's FCB.
