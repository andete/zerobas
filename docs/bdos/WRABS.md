# `WRABS` (BDOS $30) through `$F37D` — write absolute sectors

> **Spec:** DRAFT 1 (2026-11-22), one measured round on two references, no review yet.
> Its reading side, RDABS ($2F), is on [the block functions' page](BLOCKS.md); here it reads WRABS's
> sectors back.

## Summary

Through the disk ROM's BDOS entry at $F37D, WRABS takes DE = the first logical sector, H = the number of
sectors and L = the drive (0 = A), and writes H x 512 bytes from the DTA to those sectors; it answers A 0,
HL 0 and leaves the DTA. Read back with RDABS the sectors hold exactly those bytes, in order, up to the disk's
last sector (1439 on a 720 KB disk). Past the end, neither reference answers (below: Open).

zerobas writes and reads the same bytes and answers the same; only SETDTA's working registers differ
(D-F37DREGS).

## The specification

References: the Philips VG-8020 with an NMS 1200 disk interface (row `D`) AND the National CF-3300
(row `C`). Ours: zerobas's disk build.

**Evidence.** **[XA rNN]**: case `NN` on row `r` of the XBABS1 probe -- run 1
([`scratchpad/XBABS1_run1.out`](../../scratchpad/XBABS1_run1.out), `--row disk`), run 2
([`scratchpad/XBABS1_run2.out`](../../scratchpad/XBABS1_run2.out), `--row cf3300`).
`probes/bios/spec/xbabs1.asm` documents the 8 cases (SETDTA, WRABS sector 20, RDABS 20, WRABS 21 .. 22,
RDABS 22, RDABS 21 .. 22, WRABS 1439, RDABS 1439) and the 66-byte record: A, F, the FCB (not passed: start-up
RAM, not evidence), the DTA's first 13 bytes, HL, and the DTA at +383 .. +1024. The DTA's 1040 bytes hold
`($40 + the case + (i AND $FF) + (i >> 8) x 16) AND $FF` before each case, so no two sectors are alike. The
disk is the project's generated empty image. A first run with one more case -- WRABS of sector 1440, past
the end -- never came back on either reference within 60 s
([`scratchpad/XBABS1_run0_past.out`](../../scratchpad/XBABS1_run0_past.out), row D); that case was
dropped.

## Open (not measured)

- **[A]** WRABS past the disk's last sector: neither reference returns within 60 s (an error prompt
  waiting for a key?); zerobas answers A $08 at once. What the references wait for, and answer, is not
  measured.
- **[A]** H 0 (RDABS with H 0 did not return on the VG-8020 + NMS 1200); other drives (L 1 on a
  one-drive machine: the "insert disk for drive B" prompt); a write-protected disk; sectors of the boot
  sector, the FAT and the directory (and what a later FOPEN sees); a count crossing a track or side;
  more than 2 sectors; a DTA that wraps past $FFFF.
- **[A]** The same function under MSX-DOS ($0005).
