**The planner and its model, stated so it can be distrusted precisely.** Two cells may share
bytes iff no label using one can reach, or be reached from, a label using the other
(context-insensitive, conservative on edges). Cells marked **Tx** (live across an expression
evaluation or a co-routine suspension) also conflict with everything their enclosing
statement reaches (fwd∘bwd). The DRAW and CIRCLE-parse co-routines, PRINT USING's format
state and LIST's resumable render are modelled by adding the tenant's cells to the main
driver labels. Pointer-held buffer liveness is modelled coarsely: **every label reachable from
`eval`, INPUT, `read_line`, the crunch, ASCII reading or PRINT counts as a user of BUF and of
FOUTBUF's 25 bytes**; the FN shadow slots count every `FN_*` user. Two false paths were cut by
hand: `ev_f_point` and `spr_tenant` reach only their own graphics ops, not the whole
multiplexed `graphics_tenant`. **Known blind spots** (each overlay therefore still needs a gate
row): `jp (hl)` / vector calls (`ARL_GETBYTE`, hooks), `IF`-assembled variants (both arms are
parsed), writes through a pointer held in a register across a call, and the T/Tx lifetime
labels themselves (hand-assigned; listed per cell). Interrupt service: **no window cell is
referenced by `htimi_service`/`event_poll`/`play_service`/keytrap/sprtrap** (name grep of
[traps.asm](basic/traps.asm), [playsvc.asm](basic/playsvc.asm), [keytrap.asm](basic/keytrap.asm),
[sprtrap-body.inc](basic/sprtrap-body.inc)) — and none of the host buffers is touched there.

The conservative variant (`plan_tx.out`: the float/string/READ ABI cells live across their
caller's continuation) leaves **272 B** without a home instead of 247: the plan does not hinge on
the optimistic lifetimes. Without any overlap at all (`plan_noovl.out`) equates house only
~200 B — **the equate-only phase is NOT spent if overlaps are allowed; it is spent without them.**

Findings worth a line each:
- **`VALTYP` ($EF35) is write-only** — [strvar.asm:258](basic/strvar.asm:258) is its only reference in any image; the published VALTYP ($F663) is `VALTYP_PUB`.
- **`FACTYP` is the published VALTYP's job, same encoding (2/4/8)** — [usr.asm:212](basic/usr.asm:212) already copies it there; C-BIOS's GETYPR is a stub that only names VALTYP in a comment.
- **`FLD_TAB` (96 B) is read on EVERY string-variable read** ([strvar.asm:135](basic/strvar.asm:135) scalar, [strvar.asm:253](basic/strvar.asm:253) array element → `fld_lookup` → `fld_find`) and rewritten at every NEW/RUN/CLEAR ([vars.asm:1230](basic/vars.asm:1230)) on the diskless machine, where FIELD can never define an entry. Garbage there = a `fch_select` of a garbage channel on a plain `PRINT A$`.
- **`FCH_ACTIVE` is 0 on a diskless machine but READ by `chan_gate`** ([files.asm:146](basic/files.asm:146)) — persistent, must leave.
- **`DISKOP_ERR` is read diskless**: `MERGE"CAS:x"` of a non-ASCII file → `mc_ioerr` → `disk_error` ([files.asm:2333](basic/files.asm:2333), [files.asm:338](basic/files.asm:338)) raises whatever the cell holds — a stale disk code on a disk machine too.
- **`FLD_CHAN` and `LRSET_JUST` are stored before the refusal** ([field.asm:319](basic/field.asm:319), [field.asm:574](basic/field.asm:574)).
- **`CSR_ON` is genuinely persistent** — [interp.asm:236](basic/interp.asm:236) records the failure when it held garbage ($FF written to VRAM $FFFF). Same for `RL_AUTO` (read by INPUT's `read_line`, [repl.asm:186](basic/repl.asm:186)) and `PRMWANT` (spans a whole RUN).
- **The KEY-bar repaint (`keystr`) renders through the detok window** ([keystr.asm:241](sub/keystr.asm:241)) and is reachable from `INKEY$` and from `read_line` (`path.py main:read_line sub:db_begin`) — that single coupling is why `DB_WIN` (96 B) fits no published buffer.
- **The idle published pool is larger than the 2026-10-14 estimate (~140 B, ≤34 B contiguous)**: `PARM1 $F71C-$F74B` is 48 B contiguous with no declared cell (`pubfree_map.py` counted PARM1 as busy because symbols' VALUES fall in it; byte-granular it is free) **(unverified at runtime — a `ramfree-acceptance`-style fill is the witness)**.
- **`$F195-$F37F`** (above the list) holds `DSKBUF_PTR` ($F351, DSKI$/DSKO$) and the disk ROM's area — disk-only by every reference found **(unverified for DSKI$/DSKO$ on a diskless machine)**.

## (ii) Ranked slice plan to "nothing diskless below `$F380`"

The 2026-10-14 lesson stands: an intermediate ceiling only moves the stack to another spot the
games treat as free. **So every slice below is equate/code only and leaves `TXTMAX_NODISK` at
`$ECF8`; the ceiling moves ONCE, in the last slice.** Each slice is gated the way slices 1-7 were:
`wszero-acceptance` rows that load `$A5` over the cells' OLD homes and then run their users,
plus a knife that puts one cell back.

1. **S8 — the reference's own cells (30 B + SWPTMP 9 B, 0 ROM). Do first.** SAVSTK→$F6B1,
   SAVTXT→$F6AF, CONTLINE→OLDLIN $F6BE, CONTPTR→OLDTXT $F6C0, AU_NUM/RN_NEW→AUTLIN $F6AB,
   AU_INC/RN_INC→AUTINC $F6AD, GFX_DSCALE→DRWSCL $FCBC, GFX_DANGLE→DRWANG $FCBD,
   GFX_DFB→DRWFLG $FCBB, LPTPOS→LPTPOS $F415, FACTYP→VALTYP $F663, DISKSLOT_OK→DRVINF $FB21,
   DISKSLOT→$FB22, TSV_END→SAVEND $F87D, GFX_B→BRDATR $FCB2 (split from GFX_WE_P),
   ERRRESUME+2..3→ERRTXT $F6B7 (all six accesses are 2+2: [interp.asm:1420](basic/interp.asm:1420),
   1422, 1737, 1739, [errtrap.asm:73](sub/errtrap.asm:73), 76), SW_ADDR..SW_MODE→SWPTMP $F7BC (SWAP never
   runs inside BLOAD/BSAVE, whose CURPTR/ENDPTR/EXECPTR live there), SVT_SP→SWPTMP+6 $F7C2
   (must NOT overlay CURPTR..EXECPTR: the SAVE tenant runs during BSAVE). Targets checked free in
   all four syms. Witness rows: CONT after STOP; AUTO; `DRAW"S8A1"` then a second DRAW; LPRINT + LPOS;
   USR with an integer argument; ON ERROR + RESUME; SWAP of two array elements; `BSAVE"CAS:"`;
   PAINT with a border; a diskless OPEN/LOAD that must take the tape arm (DISKSLOT_OK).
   Risks: DRVINF holds a drive COUNT (zerobas writes 1; every reader tests nonzero —
   unverified at each site); LPTPOS is also zeroed by C-BIOS LPTOUT on an abort (the
   reference's semantics); the 2026-08 rehoming doc rejected SAVSTK/SAVTXT for OBSERVABILITY,
   not for conflict.
2. **S10 — the persistent diskless set into `PARM1 $F71C-$F74B`, exclusively (≈36 B incl. ERRRESUME[0..1], 0 ROM; the planner fills the hole's last 12 B with NUMBUF, GFX_DSUB, GFX_SN).**
   FCH_MODES 16, CSR_ADDR/CSR_CHAR/CSR_ON, ARL_GETBYTE, CAS_BUFP, RL_AUTO, FCH_ACTIVE,
   CONTVALID, CAL_CNT/CAL_NEEDFILL/CAL_SAVE, FCH_NUM, FCH_MODE, DIRECTF, PRMWANT (+ ERRRESUME[0..1]
   into the next free pair). These are what the NEXT statement after a load reads — the
   crash-critical rest. Witness rows: `OPEN"CAS:"…FOR OUTPUT`, load over the old homes, `PRINT#`,
   `CLOSE`; INPUT after a load (CSR_ON, RL_AUTO); `RUN` of a program that loads over PRMWANT
   (prompt); CONT. Risk: the hole is unattributed by every map, not runtime-measured — fill it
   and run the nine subsystems (the `ramfree-acceptance` pattern) before relying on it.
3. **S9 — disk-only / dead bookkeeping (~+12-17 B main p1, ~+5 B sub p0; legitimises 291 B).**
   Delete VALTYP's store (−3 B) and FOSIGN/FOMBYTES; store FLD_CHAN after `fch_mode_class` (0 B,
   E survives it); retarget `mc_ioerr` to `load_error` (0 B, also fixes the stale-code bug);
   move LRSET_JUST's store past the H.LSET/H.RSET gate (~2-4 B); gate `fld_init` and `fld_find`
   (and sub `aer_fldfix`) on DISKSLOT_OK (~10 + ~5 B); split the aliases whose halves differ
   (FMT_GEOMSEL/TSV_CNT, FMT_RESULT/TSV_NAME, FILES_ENTIDX/IN_RDLEN, DISKOP_A/PLY_NUMOVF);
   DISK-ONLY tags on all D cells and a BOOT-ONLY tag (new `ram_map --check` rule) for SCAN_*.
   Witness: FIELD / LSET on a CAS channel, MERGE of a tape binary, ERASE + string reads, all
   after a load over the old homes, diskless; the disk machine's FIELD/GET/PUT rows unchanged.
4. **S11 — transient cells into the remaining idle published bytes (~157 B, 0 ROM).** The
   planner's `(a′)` rows: HIGH_..ENDPRG, TRPTBL tail, ARG tail, DAC tail (C-BIOS names DAC in
   sources not in the repack — unverified), MAXUPD/MINUPD, CONLO tail/MEMSIZ, NTMSXP..VLZDAT,
   DONUM..CONTYP, LFPROG..MCLFLG, XSAVE/YSAVE, FILTAB/NULBUF, singles. Sharing only between
   statement-exclusive cells. Witness: the `rich`/`rich2` rows extended to each user.
5. **S12 — overlays on published buffers (310 B, 0 ROM; the riskiest equate slice).** BUF gets
   only statement-tenant internals (LINE/box Bresenham, CIRCLE draw, arc mask, PLAY parse SP);
   MULPROD+DIVPAD gets transient cells no `fp_mul`/`fp_div`/RND path can reach (DIVREM is
   provably exclusive with MULPROD's head: `rng.py DIVREM F82A 15`); FBUFFR gets its idle tail
   and FBUFFR+0; the FN shadow slots (dead outside an FN call; `FN_FEND` is outside them) get
   PU_DIG. Every overlap pair needs a row that runs both users in one program.
6. **S13 — the risky published 42 B** (SLTWRK entries of slot 0's sub-slots 1-3 and page 3 —
   unreachable for any ROM while slot 0 is not expanded, true on the repack machine,
   unverified for the VG-8020; PROCNM — would be needed by a faithful `CALL` to an extension
   ROM). **Joost's call**; if refused, these 42 B join S14.
7. **S14 — code changes for the 247 B with no exclusive home** (each its own witness):
   DB_WIN 96 (decouple the KEY-bar repaint from the detok window, then BUF; or shrink the
   window; ~20-40 B sub), DRAW X-frame stack GFX_DFTOP+GFX_DFSTK 33 (main reserves it on the Z80
   stack in `ex_draw`, base in a 2-B cell, tenant indexes it; ~10 B main p1 + ~20 B sub p0),
   GFX_VBUF 32 (stage SPRITE$ in STRSCR with the `strscr_desc` discipline; ~0-10 B), FOR_CUR..FOR_SIGN
   26 (evaluate STEP before storing the limit, then the FN shadow slots; ~6 B main p1), CVT 18
   (SP frame in `domain_convert_core`, ~25 B main p0 — no published buffer is exclusive with it:
   `fp_mul` and `fp_sqrt` reach it), HORNER_G/MATH_A 36 (IX frame in the sub math tenants, ~60 B
   sub p1; MATH_N/MATH_BREAK are also written by main `cpow_*`). **Nothing looks infeasible;
   DB_WIN and the math frame are the expensive ones.**
8. **S15 — the ceiling.** When a census like `census.py` shows no diskless reference left in
   `[$ECF8,$F380)` (and `ram_map --check` passes with the DISK-/BOOT-ONLY tags):
   `TXTMAX_NODISK equ $F380`, re-check the boot choice at [interp.asm:198](basic/interp.asm:198)
   (it compares HIMEM's high byte with TXTMAX's), and grep every block fill whose base is a
   former window name (`ifc_zero` in `init_filechan`, `fld_init`, …) for a reach into program
   RAM. **Whether SP then lands at the reference's ~$F09E depends on POOLSIZE + the channel
   blocks below the ceiling summing to the reference's FCB area (~738 B) — not on this
   classification (unverified).**
