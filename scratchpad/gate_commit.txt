FIX (5) MADE THE SCRAPE READ THE CODE COLUMN. IT DID NOT MAKE THE SCRAPE
CORRECT. It was still a PROXY for "what can reach main code from outside main?",
and a proxy is coarse in more directions than the one you just closed: a name
referenced in sub/ CODE seeded the MAIN label of that name even when the sub
reference resolved SUB-LOCALLY. That is the normal case, not an odd one.
sub/fatprim.asm's `call fat_read_fat_sector` reaches basic/fat-prim-body.inc's
own copy; sub/format.asm DEFINES its own write_sector.

THE FIX IS NOT A NARROWER PROXY. sub/basic-resident-abi.inc is GENERATED from
build/basic-reloc.sym and is the ONLY file in the tree that imports a main
address. Everything else a sub file names resolves sub-locally or the sub build
does not assemble. So that import list IS the sub->main surface rather than a
proxy for it -- a strictly stronger claim than "the scrape is coarse", and the
reason this is a redesign and not a strip.

MEASURED ON THE WHOLE SET, NOT ON THE FOUR THAT PROMPTED IT: 65 main labels are
named in sub/ code; 65 of 65 resolve inside the sub build (12 via the ABI, 53
sub-local); 0 escapes. That measurement ships as
_assert_sub_resolves_locally() -- a STANDING CONTROL on the one assumption that
lets sub/ stop seeding main. The invariant is enforced by the assembler, but
"the assembler owns it" is the kind of reasoning that rots when nothing re-runs
it, and this sweep would go QUIET rather than loud if it stopped holding.

before the run, run twice, all EXACT (scratchpad/seedhole2_knives.py):
  K1 ABI import emptied              -> rc 1, floor fires
  K2 ABI names a non-label           -> rc 1, "do not resolve"
  K3 plant, no mention               -> reported by BOTH scrapers
  K4 plant + sub CODE call + a SUB-LOCAL definition -> new reports, OLD BLIND
  K5 plant + sub CODE call, NOT sub-resolvable      -> rc 1, escape control fires

K3 is what makes K4 readable. K4 IS THE SLICE and is deliberately the
real-world shape -- the same name, called from sub code, WITH the sub-local
definition that makes the call resolve there. K6 and K7 are what make it
honest: without K6, "we dropped sub/" could be "we broke the code column too";
without K7 it could be "we seed nothing but init". Sec 6.1's four modes
re-verified: gate/clean rc 0, gate/blind rc 1 WITH THE ALLOWLIST CANARY FIRING,
report/clean rc 0, report/blind rc 0.
