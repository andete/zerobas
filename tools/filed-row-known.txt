# 🔴 THE POINT IS THE COMPLEMENT. A divergence in this file is
# *measured-and-known* -- filed, adjudicated, or deliberately declined. A
# divergence NOT in this file is *measured-and-unnoticed*, which is the thing
# the sweep exists to make loud. And a row in this file that STOPS diverging is
# the CVI shape again -- fixed-when-filed, entry stale -- so the sweep reports
# that too rather than silently dropping it.
